# SVG 图标生成器

## 概述

该技能用于在 **Visual Content（视觉内容）** 领域中，辅助完成 SVG 图标生成相关任务。  
它可以帮助用户根据需求生成 SVG 图标代码、优化图标结构、检查 SVG 的可用性，并输出适合生产环境使用的配置与代码。

## 适用场景

当用户提出以下需求时，可以使用该技能：

- 提到 `svg icon generator`、`svg generator`、`svg`、`SVG 图标`、`SVG 生成器` 等关键词；
- 需要生成 SVG 图标、图标代码或矢量图形；
- 需要设计适合系统、网站、应用、控制台、菜单、按钮等场景使用的图标；
- 需要优化 SVG 代码结构，例如清理冗余属性、统一尺寸、压缩路径、规范命名；
- 需要根据视觉内容需求生成图表、示意图、演示文档或视觉文档中的图标元素；
- 需要 SVG 图标相关的模式、最佳实践或实现建议。

## 使用说明

执行 SVG 图标生成任务时，应遵循以下步骤：

1. **理解需求**
   - 明确图标主题、使用场景、视觉风格、尺寸、颜色、线条粗细等要求；
   - 如果用户没有指定，默认生成简洁、现代、可复用的 SVG 图标。

2. **设计图标结构**
   - 优先使用标准 SVG 元素，例如 `svg`、`path`、`circle`、`rect`、`line`、`polyline`、`polygon`；
   - 保持结构简洁，避免不必要的复杂路径；
   - 默认使用 `viewBox` 控制图标缩放能力。

3. **生成可用代码**
   - 输出可直接使用的 SVG 代码；
   - 保证代码结构清晰、属性完整、可复制粘贴；
   - 尽量避免依赖外部资源，确保 SVG 可独立渲染。

4. **遵循最佳实践**
   - 保持图标尺寸一致，例如 `24x24`、`32x32` 或用户指定尺寸；
   - 使用语义清晰的属性；
   - 对于线性图标，建议使用 `stroke="currentColor"`，便于前端继承文本颜色；
   - 对于填充图标，建议使用 `fill="currentColor"` 或用户指定色值；
   - 避免硬编码无必要的颜色，除非用户明确要求；
   - 避免使用过多嵌套、滤镜、渐变和复杂效果，除非业务场景需要。

5. **校验输出**
   - 检查 SVG 标签是否完整闭合；
   - 检查 `viewBox`、`width`、`height` 是否合理；
   - 检查路径、线条、填充、描边是否符合需求；
   - 确认输出可以被浏览器、前端框架或设计工具正常使用。

## 错误处理

| 错误类型 | 可能原因 | 解决方案 |
|---|---|---|
| 配置无效 | 缺少必要字段或参数 | 检查文档，补充必需参数 |
| 工具未找到 | 依赖工具未安装 | 根据前置条件安装所需工具 |
| 权限不足 | 当前环境没有读写或执行权限 | 检查账号、目录、文件或命令权限 |
| SVG 无法显示 | 标签未闭合、路径错误或属性缺失 | 检查 SVG 结构和关键属性 |
| 图标样式不符合预期 | 尺寸、颜色、描边或填充设置不合理 | 根据使用场景调整 `viewBox`、`stroke`、`fill` 等属性 |
| 前端无法继承颜色 | 使用了固定颜色 | 改为 `currentColor` 或按项目规范配置颜色变量 |
