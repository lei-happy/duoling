# Mermaid 图表渲染测试

本文档用于验证文档中心对 Mermaid 图表的渲染支持，包含流程图、时序图、甘特图、类图等常用图表类型。

---

## 1. 流程图（Flowchart）

以下是一个用户下单的业务流程图：

```mermaid
flowchart TD
    A[用户发起下单] --> B{库存是否充足}
    B -->|是| C[生成订单]
    B -->|否| D[提示库存不足]
    C --> E[扣减库存]
    E --> F[发送订单通知]
    F --> G[等待支付]
    G --> H{支付是否成功}
    H -->|是| I[订单确认]
    H -->|否| J[订单取消]
    J --> K[恢复库存]
    I --> L[安排发货]
```

## 2. 时序图（Sequence Diagram）

用户登录认证的时序图：

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant B as 后端API
    participant DB as 数据库
    participant R as Redis

    U->>F: 输入账号密码
    F->>B: POST /api/auth/login
    B->>DB: 查询用户信息
    DB-->>B: 返回用户记录
    B->>B: 校验密码
    alt 密码正确
        B->>R: 存储 Token
        B-->>F: 返回 Token + 用户信息
        F->>F: 缓存 Token
        F-->>U: 跳转首页
    else 密码错误
        B-->>F: 返回错误信息
        F-->>U: 提示密码错误
    end
```

## 4. 类图（Class Diagram）

系统核心模型的类图：

```mermaid
classDiagram
    class User {
        +int id
        +string username
        +string phone
        +string avatar
        +login()
        +logout()
    }

    class Tenant {
        +int id
        +string tenantCode
        +string companyName
        +int status
        +activate()
        +suspend()
    }

    class Vehicle {
        +int id
        +string plateNumber
        +string brand
        +int status
        +assign()
        +release()
    }

    class Driver {
        +int id
        +string realName
        +string licenseNo
        +int status
        +bind()
        +unbind()
    }

    class Waybill {
        +int id
        +string waybillNo
        +int status
        +create()
        +dispatch()
        +complete()
    }

    User "1" --> "*" Tenant : 管理
    Tenant "1" --> "*" Vehicle : 拥有
    Tenant "1" --> "*" Driver : 雇佣
    Driver "1" --> "*" Waybill : 执行
    Vehicle "1" --> "*" Waybill : 承运
```
