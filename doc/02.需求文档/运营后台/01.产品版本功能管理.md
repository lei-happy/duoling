# 产品版本功能管理

> **所属阶段**：阶段二 - 运营后台完善
>
> **文档状态**：待编写
>
> **优先级**：高（核心 SaaS 能力）

## 一、功能概述

实现产品版本与功能清单的关联管理，控制不同版本企业可使用的功能模块。

## 二、业务背景

当前产品版本（basic/standard/pro/enterprise）已有基础 CRUD，但缺少版本与具体功能模块的关联控制。企业登录后应根据其所购版本动态展示可用功能。

## 三、需求详情

### 3.1 功能清单管理

- 维护平台所有功能模块清单（feature_code, feature_name, module, description）
- 功能分组：按业务模块分组展示（基础模块、资源模块、业务模块、财务模块、BI 模块）

### 3.2 版本功能配置

- 在产品版本详情页增加"功能配置"Tab
- 以勾选方式配置每个版本包含的功能项
- 支持批量勾选/取消

### 3.3 功能权限控制

- 菜单表（sys_menu / biz_menu）增加 feature_code 字段
- 企业端登录时：查询企业授权版本 → 获取功能清单 → 过滤菜单
- 未授权功能的菜单不展示，API 端点返回 403
