# 开放平台 - 数据库设计

> 上级文档：[00.模块总览](00.模块总览.md)
>
> 本文回答：新增哪些表、放平台库还是租户库、字段与索引、迁移方式。
>
> 落地时对应 SQL 归档到 `doc/03.数据库设计/01.平台库数据表/`（open_* 表）与 `doc/03.数据库设计/02.租户业务库数据表/`（biz_open_call_log）。

## 一、分库原则

| 数据 | 库 | 理由 |
|------|----|----|
| 应用、凭证、MCP 配置、能力目录 | **平台库 `zt_platform`** | 身份/契约是跨租户的平台级资产；数据面鉴权只需一次平台库查询即可定位租户，鉴权快、连接池可控 |
| 调用审计流水 | **租户库 `zt_biz_{code}`** | 高频、量大、租户自查、随租户物理隔离 |

> 与现有约定一致：身份类（如 `sys_user`、`open_register_task`）在平台库；业务高频数据（如 `biz_*`）在租户库。应用/凭证含 `tenant_code` 列关联租户，模式对齐 `sys_tenant_product`。

## 二、平台库表

### 2.1 `open_app` 接入应用

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | varchar(36) PK | 应用 UUID |
| `tenant_code` | varchar(32) | 所属租户 |
| `name` | varchar(64) | 应用名称（用户填，如"我们的 ERP"） |
| `description` | varchar(255) | 用途备注 |
| `status` | varchar(16) | `enabled` / `disabled` |
| `created_by` | bigint | 创建人 user_id |
| `created_at` / `updated_at` / `is_deleted` | | 标准审计列 |

索引：`ix_open_app_tenant(tenant_code)`。

```sql
--数据库名称：zt_platform
--表名称：open_app
CREATE TABLE `open_app` (
  `id` varchar(36) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '应用 UUID',
  `tenant_code` varchar(32) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '所属租户',
  `name` varchar(64) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '应用名称',
  `description` varchar(255) COLLATE utf8mb4_unicode_ci NOT NULL DEFAULT '' COMMENT '用途备注',
  `status` varchar(16) COLLATE utf8mb4_unicode_ci NOT NULL DEFAULT 'enabled' COMMENT 'enabled disabled',
  `created_by` bigint DEFAULT NULL COMMENT '创建人 user_id',
  `created_at` datetime NOT NULL DEFAULT (now()) COMMENT '创建时间',
  `updated_at` datetime NOT NULL DEFAULT (now()) ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted` smallint NOT NULL DEFAULT '0' COMMENT '是否删除 0-否 1-是',
  PRIMARY KEY (`id`),
  KEY `ix_open_app_tenant` (`tenant_code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='开放平台接入应用';
```

### 2.2 `open_credential` 接入凭证

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | varchar(36) PK | 凭证 UUID |
| `app_id` | varchar(36) | 所属应用 |
| `tenant_code` | varchar(32) | 冗余，便于数据面单表定位租户 |
| `cred_type` | varchar(16) | `api`（AppKey/Secret）/ `mcp`（Token） |
| `access_key` | varchar(64) | AppKey `ak_*` 或 MCP `mcp_*` 标识，**唯一索引** |
| `secret_hash` | varchar(128) | AppSecret / Token 的哈希（永不存明文） |
| `scope` | json | 授权能力码白名单，如 `["waybill.query"]` |
| `ip_whitelist` | varchar(512) | 可选，逗号分隔 CIDR |
| `status` | varchar(16) | `enabled` / `disabled` / `revoked` |
| `expires_at` | datetime NULL | 到期时间，NULL=长期有效 |
| `last_used_at` | datetime NULL | 最近调用时间 |
| `created_by` / `created_at` / `updated_at` / `is_deleted` | | |

索引：唯一 `uk_open_cred_ak(access_key)`；`ix_open_cred_app(app_id)`；`ix_open_cred_tenant(tenant_code)`。

> 数据面鉴权路径：`access_key` → 命中唯一索引 → 取 `tenant_code/scope/status/secret_hash/expires_at`，一次查询完成路由 + 校验；结果按短 TTL 缓存到 Redis，吊销时主动失效。

### 2.3 `open_mcp_config` MCP 配置

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | varchar(36) PK | 配置 UUID |
| `app_id` | varchar(36) | 所属应用 |
| `tenant_code` | varchar(32) | 冗余定位租户 |
| `credential_id` | varchar(36) | 绑定的 MCP 凭证（`cred_type=mcp`） |
| `server_slug` | varchar(32) | URL 路径片段，**唯一**，如 `7f3a9c2e` |
| `display_name` | varchar(64) | 用户自定义连接名称（可改，不影响连接） |
| `enabled_capabilities` | json | 暴露为 MCP Tool 的能力码 |
| `status` | varchar(16) | `enabled` / `disabled` |
| `created_by` / `created_at` / `updated_at` / `is_deleted` | | |

索引：唯一 `uk_open_mcp_slug(server_slug)`；`ix_open_mcp_app(app_id)`。

> `display_name` 与 `server_slug` 分离：改名只动 `display_name`，`slug`/`token` 不变，用户已粘贴的配置无需更新（见 `04` §六）。

### 2.4 `open_capability` 能力目录

事实源在代码 `@register_capability`；本表为**同步产物**，供控制面展示与文档生成。

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | varchar(64) PK | 能力码，如 `waybill.query` |
| `name` | varchar(64) | 业务名称 |
| `category` | varchar(32) | 分类 |
| `description` | varchar(512) | 说明 |
| `channels` | json | `["api","mcp"]` |
| `read_only` | smallint | 是否只读 |
| `input_schema` | json | 入参 JSON Schema |
| `output_fields` | json | 对外字段白名单 |
| `sensitive_fields` | json | 脱敏字段 |
| `risk_level` | varchar(16) | `low` / `high` |
| `stability` | varchar(16) | `beta` / `stable` / `deprecated` / `offline` |
| `version` | varchar(8) | `v1` |
| `status` | varchar(16) | `enabled` / `disabled` |
| `sort_order` | int | 展示排序 |
| `created_at` / `updated_at` | | |

索引：`ix_open_cap_category(category)`；`ix_open_cap_status(status)`。

## 三、租户库表

### 3.1 `biz_open_call_log` 调用审计

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | varchar(36) PK | 日志 UUID |
| `request_id` | varchar(48) | 全局请求号 |
| `app_id` | varchar(36) | 调用方应用 |
| `credential_id` | varchar(36) | 调用方凭证 |
| `channel` | varchar(8) | `api` / `mcp` |
| `capability_code` | varchar(64) | 能力码，越权/未命中可空 |
| `method` | varchar(8) | HTTP 方法 |
| `path` | varchar(255) | 请求路径 |
| `params_masked` | text | 脱敏入参 |
| `status` | varchar(16) | `success` / `failed` / `denied` |
| `error_code` | varchar(32) | 错误码 |
| `http_status` | smallint | HTTP 状态码 |
| `latency_ms` | int | 耗时毫秒 |
| `client_ip` | varchar(64) | 来源 IP |
| `user_agent` | varchar(255) | UA |
| `result_summary` | varchar(255) | 结果摘要（如返回条数），不存全量 |
| `created_at` | datetime | 时间 |

索引：`ix_ocl_created(created_at)`；`ix_ocl_app(app_id)`；`ix_ocl_cap(capability_code)`；`ix_ocl_status(status)`；`ix_ocl_reqid(request_id)`。

```sql
--数据库名称：zt_biz_{tenant_code}
--表名称：biz_open_call_log
CREATE TABLE `biz_open_call_log` (
  `id` varchar(36) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '日志 UUID',
  `request_id` varchar(48) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '全局请求号',
  `app_id` varchar(36) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '调用方应用',
  `credential_id` varchar(36) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT '调用方凭证',
  `channel` varchar(8) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT 'api mcp',
  `capability_code` varchar(64) COLLATE utf8mb4_unicode_ci NOT NULL DEFAULT '' COMMENT '能力码',
  `method` varchar(8) COLLATE utf8mb4_unicode_ci NOT NULL DEFAULT '' COMMENT 'HTTP 方法',
  `path` varchar(255) COLLATE utf8mb4_unicode_ci NOT NULL DEFAULT '' COMMENT '请求路径',
  `params_masked` text COLLATE utf8mb4_unicode_ci COMMENT '脱敏入参',
  `status` varchar(16) COLLATE utf8mb4_unicode_ci NOT NULL COMMENT 'success failed denied',
  `error_code` varchar(32) COLLATE utf8mb4_unicode_ci NOT NULL DEFAULT '' COMMENT '错误码',
  `http_status` smallint NOT NULL DEFAULT '0' COMMENT 'HTTP 状态码',
  `latency_ms` int NOT NULL DEFAULT '0' COMMENT '耗时毫秒',
  `client_ip` varchar(64) COLLATE utf8mb4_unicode_ci NOT NULL DEFAULT '' COMMENT '来源 IP',
  `user_agent` varchar(255) COLLATE utf8mb4_unicode_ci NOT NULL DEFAULT '' COMMENT 'UA',
  `result_summary` varchar(255) COLLATE utf8mb4_unicode_ci NOT NULL DEFAULT '' COMMENT '结果摘要',
  `created_at` datetime NOT NULL DEFAULT (now()) COMMENT '创建时间',
  PRIMARY KEY (`id`),
  KEY `ix_ocl_created` (`created_at`),
  KEY `ix_ocl_app` (`app_id`),
  KEY `ix_ocl_cap` (`capability_code`),
  KEY `ix_ocl_status` (`status`),
  KEY `ix_ocl_reqid` (`request_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='开放平台调用审计';
```

> `biz_open_call_log` 为 `open_platform` 功能的 `required_tables`，随功能开通由 `ensure_tenant_tables` 建表；租户首访自愈同 AI 模块 `ensure_biz_ai_tables` 范式。审计无 `is_deleted`（只追加、按时间归档）。

## 四、ORM 与迁移

| 项 | 做法 |
|----|----|
| 平台库 ORM | `open_platform/models/platform/`，继承 `PlatformModelBase`（varchar 主键用 `PlatformBase`） |
| 租户库 ORM | `open_platform/models/tenant/`，继承 `TenantModelBase`，`__table_tier__` 归 `business` |
| 平台库迁移 | Alembic autogen（对齐 `.cursor/rules/database-migration.mdc`），产物入 `backend/migrations/` |
| 租户库迁移 | 自研 runner + snapshot（`backend/scripts/migration/`）；`open_platform` feature 的 `required_tables` 注册 `biz_open_call_log` |
| SQL 归档 | 平台库 SQL 补入 `doc/03.数据库设计/01.平台库数据表/`；租户库 SQL 补入 `doc/03.数据库设计/02.租户业务库数据表/` |

## 五、数据留存与容量

- `biz_open_call_log` 会随调用量快速增长，建议：
  - 按 `created_at` 建索引支持时间范围查询与归档。
  - 留存策略（如热数据 90 天，冷数据归档/清理），远期可按月分表或转时序/日志存储。
- 平台库 `open_*` 表数据量小，无特殊容量考量。
