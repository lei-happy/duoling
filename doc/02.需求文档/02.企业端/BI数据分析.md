## 一、功能概述

为企业提供运营数据分析看板，包括运营概览、车辆分析、客户分析、路线分析、驾驶员分析等多维度数据可视化。

## 二、业务背景

前端已集成 ECharts 图表库，有 Dashboard 模板页面。需设计后端统计查询 API 并开发前端看板。

## 三、需求详情

### 3.1 运营概览
- 运单量趋势、收入趋势、成本趋势、利润率

### 3.2 车辆分析
- 车辆利用率、空驶率、各车收入排名

### 3.3 客户分析
- 客户贡献度、运单量排名、回款率

### 3.4 路线分析
- 路线盈利排名、频次、平均时效

### 3.5 驾驶员分析
- 出勤率、运单完成量、绩效评分
