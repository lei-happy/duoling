## 一、模块定位与设计目标

### 1.1 定位

系统设置是企业端**租户级业务参数与安全策略**的统一配置入口，面向企业管理员。与「系统管理」（组织/员工/角色）不同，本模块不管理人员与权限，而是管理**全租户生效的运行时行为**——例如运单运费展示策略、任务编号规则、页面水印等。

| 入口 | 路由 | 菜单 feature_code | 数据存储 |
|------|------|-------------------|----------|
| 系统设置 | `/enterprise/config` | `base_config` | 主要走 `biz_system_config` |
| 企业信息（品牌名称） | `/enterprise/manage` | — | 走 `/enterprise/system-name`，**非** `biz_system_config` |

> 旧路径 `/system/config` 已迁移至 `/enterprise/config`，以客户端菜单快照为准。

### 1.2 设计目标

| # | 目标 | 落点 |
|---|------|------|
| 1 | **租户级统一策略**：管理员改一次，全租户登录用户生效 | `biz_system_config` + layout/业务页读取 |
| 2 | **分组可扩展**：运单、任务、安全等分组独立面板 | `config_group` + 专用 Vue 组件 |
| 3 | **变更即保存**：与现有运单设置一致，单项 PUT 持久化 | `PUT /system/config/{key}` |
| 4 | **首期聚焦数据安全**：页面水印防截图外传 | 见 `01.系统水印设置.md` |

### 1.3 不在本期范围

| 不做 | 原因 | 未来路径 |
|------|------|---------|
| Console 管理端水印 | 首期仅 Client 企业端 | 独立需求 |
| 驾驶员 H5 / 移动端水印 | 端形态与布局不同 | 复用配置键，端侧单独渲染 |
| 按业务模块勾选水印范围 | 易留安全盲区，配置复杂 | 远期可按路由黑名单扩展 |
| 企业 Logo / 主题色租户配置 | 属品牌与账号偏好，已有独立链路 | `enterprise/manage` + `theme_config` |

## 三、现有实现基线

前端页面：[`frontend/client/src/views/enterprise/config/`](../../../../frontend/client/src/views/enterprise/config/)

布局：`ele-split-panel` 左侧 `ele-menus` 按 `configGroup` 分组，右侧专用或通用表单面板。

| config_group | 侧栏名称 | 配置项（config_key） | 右侧面板 |
|---|---|---|---|
| `waybill` | 运单设置 | `waybill.freight_calc_mode`、`waybill.list_show_freight_amount`、`waybill.auto_confirm_on_create` | `waybill-settings.vue` |
| `task` | 任务单设置 | `task.no_gen_rule`、`task.name_gen_rule` | `task-settings.vue` |
| `security` | 水印设置 | `system.watermark_enabled`、`system.watermark_content`、`system.watermark_style` | `watermark-settings.vue`（本期新增） |
| 其他 | 其它 | 未映射项 | `generic-group-settings.vue` |

**保存模式**：页面内 `ref` 直接调用 API，无专用 Pinia Store。参考运单敏感字段开关：配置页 → `biz_system_config` → 业务页 / layout 联动。

**后端**：[`system_config_service.py`](../../../../backend/app/modules/client/services/system_config_service.py) 读写 `biz_system_config`；新租户种子见 [`tenant_service.py`](../../../../backend/app/modules/console/services/tenant/tenant_service.py)。

## 五、术语表

| 术语 | 含义 |
|------|------|
| `config_group` | `biz_system_config` 分组字段，驱动系统设置左侧菜单 |
| `config_key` | 配置唯一键，如 `system.watermark_enabled` |
| 全局水印 | 登录后在 layout 层 fixed 覆盖视口，非按模块勾选 |
| 模板变量 | 水印文本中的 `{nickname}` 等占位符，运行时按当前用户解析 |
