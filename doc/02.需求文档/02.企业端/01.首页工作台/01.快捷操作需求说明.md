# 快捷操作 — 需求说明

> **所属模块**：智能工作台 · 今日工作台（`/dashboard/workplace`）
>
> **关联文档**：`doc/02.需求文档/02.企业端/01.客户端菜单架构重构设计.md` §5.1、`doc/04.开发手册/15.快捷操作接入说明.md`

## 1. 模块定位

快捷操作是今日工作台顶部的**高频入口区**，帮助用户一键进入常用业务页面（如新建运单、新建配载、运单列表等），减少在侧栏中逐级查找的操作成本。

与下方「我的待办」「最新动态」等卡片不同：快捷操作强调**跨模块跳转**，且支持用户按个人习惯自定义。

## 2. 用户故事

| 角色 | 诉求 |
|------|------|
| 调度员 | 登录后快速「新建运单」「新建配载」，无需记忆菜单路径 |
| 商务 | 将「客户管理」固定在首页，方便日常维护 |
| 管理员 | 收回某按钮权限后，对应快捷入口自动消失，无需额外配置 |
| 多设备用户 | 在 A 电脑配置的快捷操作，在 B 电脑登录同一账号后保持一致 |

## 3. 功能需求

### 3.1 默认展示

- 新用户（服务端无配置）时，按注册表中 `defaultVisible: true` 的项生成初始列表。
- 初始列表仍须通过**权限 / 功能码**过滤；无权限的默认项自动跳过。
- 首次生成默认列表后写入服务端，实现跨设备同步。

### 3.2 自定义

- 用户可通过「管理」打开弹窗：
  - **已添加**：以 Tag 展示，支持关闭移除；
  - **可添加**：按业务分组展示当前有权限、尚未添加的入口。
- 已选区支持**拖拽排序**。
- 数量限制：**0 ~ 12** 项。

### 3.3 权限过滤

- **可选池**：注册表中 `permission` / `feature` 校验通过，或（无 permission 时）目标 path 在用户菜单树中的项。
- **展示栏**：用户已选 key ∩ 当前仍有权限的项；权限收回后静默隐藏，不报错。
- 用户只能添加自己有权限的操作，不能添加无权限项。

### 3.4 持久化

- 服务端字段：`sys_user.workplace_config`（JSON）。
- 结构：`{ "version": 1, "quickActions": ["waybill.create", ...] }` — 仅存 key 顺序，元数据来自前端注册表。
- API：
  - `GET /auth/user-info` → `workplaceConfig`
  - `PUT /auth/user-workplace-config`
- 保存策略：变更后防抖 1.5s 写入服务端（与主题配置一致）。

### 3.5 重置

- 工作台底部「重置布局」时，快捷操作恢复为注册表默认项（经权限过滤后的结果）。

## 4. 非功能需求

| 项 | 说明 |
|----|------|
| 最多 12 项 | 前后端双重校验 |
| 权限变更 | 菜单版本刷新 / 重新拉取 user-info 后自动重算展示项 |
| 废弃 localStorage | 不再使用 `workplace-links`；以服务端为准 |
| 可扩展 | 新业务接入仅改注册表 + 接入手册，不改 UI 组件 |

## 5. 与 §5.1 今日工作台的关系

客户端菜单架构 §5.1 要求今日工作台提供「快捷操作入口（新建运单、新建调度等）」。本模块即为该能力的正式实现，后续可扩展：

- 更多业务注册项（审批、财务等）；
- 生态平台快捷卡片（远期，通过 `feature` 门控）。

## 6. 验收要点

1. 有 `business:waybill:add` 权限的用户可见并可添加「新建运单」。
2. 无权限用户看不到对应项，也无法通过接口伪造添加（前端过滤 + 点击无效）。
3. 拖拽排序、增删后刷新页面 / 换浏览器，配置保持一致。
4. 「重置布局」恢复默认快捷操作集合。
