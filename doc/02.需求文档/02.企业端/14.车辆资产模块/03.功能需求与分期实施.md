## 二、一期功能需求（维修保养）

### 2.1 维保看板

| 区块 | 内容 | 交互 |
|------|------|------|
| 保养待办 | 已到期 / N 日内到期 | 一键「生成保养工单」 |
| 进行中工单 | 状态=进行中 | 跳转详情 |
| 本周摘要 | 完工数、费用合计 | 只读 |

空态：「暂无待办保养。可先在「保养计划」里为车辆设好周期。」

### 2.2 维修工单

#### 字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 工单号 | 系统 | 见 `04` |
| 类型 | 是 | repair / maintenance |
| 车辆 | 是 | 自有车 |
| 关联保养计划 | 否 | 保养类可关联 |
| 标题/故障简述 | 是 | |
| 进厂里程 | 否 | km |
| 维修厂/地点 | 否 | |
| 预计完工日 | 否 | |
| 费用合计 / 明细备注 | 否 | |
| 附件 | 否 | |
| 状态 | 系统 | 见状态机 |

#### 状态机

`draft` → `in_progress` → `completed`；任意未完成可 → `cancelled`。

**开工规则**：

1. 车辆须为正常；同车已有进行中工单则拒绝。
2. 绑定运力为运输中 → 禁止，提示先完成运输任务。
3. 成功：车辆 `status=2` + `status_source=maintenance`；运力 `operation_status=5`。

**完工/取消**：无其他进行中工单时回落车辆正常、运力可接单；费用不强制。

### 2.3 保养计划

周期：`time` / `mileage` / `either`；提前提醒天数默认 7。  
生成工单默认草稿；**完工时**回写计划上次日期/里程。  
里程一期可手工；无里程则仅按时间提醒。

## 三、二期：固定资产成本 + 工单/库存加厚

| 能力 | 要点 |
|------|------|
| 保险/年检台账 | 金额 + 回写到期日 + 关闭证照告警 |
| 资产卡片 | 购入日、原值、残值、折旧月数；直线法 |
| 单车资产成本页 | 维保+保险+年检+折旧；明示经营视角、非总账 |
| **工单做厚** | 故障分类、项目/工时行、备件行、维修厂主数据；费用按行汇总 |
| **轻量备件仓** | 备件主数据、库存数量、安全库存、入库/调整、完工出库扣减与流水 |
| 维保看板 | 低库存提示；可摘要跳转证照（不复制扫描） |

**库存边界（本切片）**：租户级单仓虚拟库存；不做多仓/库位/批次序列号；不做采购订单与供应商结算；开工不预占，**完工时扣减**。

## 四、三期骨架

事故、司机报修；利润分析/BI 消费资产成本（配件主数据与库存已前置到二期加厚）。

| 位置 | 行为 |

## 六、验收标准

### 6.1 一期必过

| # | 场景 | 期望 |
|---|------|------|
| 1 | standard：运力中心 → 车辆资产 | 仅见证照监控 |
| 2 | pro：车辆资产 | 见证照监控 + 维修保养 |
| 3 | pro 打开维修保养 | 看板/工单/计划，无 Placeholder |
| 4 | 开工 / 运输中拒绝 / 完工回落 | 同原维保联动验收 |
| 5 | 同车第二张进行中工单 | 拒绝 |
| 6 | 保养提醒与生成工单 | 看板可见、可生成 |
| 7 | lite | 无车辆资产深层能力（随运力中心授权而定，不单独售卖证照包） |

### 6.2 文案

- 「正在保存工单，请稍候…」
- 「已开工，运力已同步为维修保养中」
- 「该车运输任务尚未结束，请先完成任务再安排进厂」
- 升级：「维修保养是专业版能力…」

### 6.3 二期摘要

续期回写到期日；单车四类成本勾稽；折旧可算；页面声明非总账。
