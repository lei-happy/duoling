# 首页推广位 Banner 管理（Console 配置 + Client 展示 + 点击/曝光埋点）

> 状态：设计稿 · 联动 Console 运营后台与 Client 企业客户端 · 不涉及驾驶员 H5

## 1. 背景与目标

客户端「今日工作台」首页顶部有一个 Banner 推广位（`banner-card.vue`），当前为**硬编码 4 屏轮播 + 渐变占位图**，无法运营。

本次改造目标：

1. Console 端新增「运营推广 / Banner 管理」模块，运营人员可在后台配置推广内容（新功能介绍、行业资讯等）。
2. 推广位面向**已开通（已登录）的企业客户**展示，Banner 支持三种交互：只看不跳、跳转外链、跳转站内路由。
3. 支持**曝光（view）+ 点击（click）**埋点，Console 可查看「哪些租户的哪些用户查看/点击了推广」，并提供聚合报表（PV/UV/CTR）与用户级明细下钻。
4. 支持**定向投放**：全部客户 / 按产品版本 / 指定租户。
5. 支持**排期**（生效/失效时间）与**上下线**状态管理。

## 2. 数据归属决策

| 数据 | 归属库 | 迁移方式 | 理由 |
|---|---|---|---|
| Banner 配置 | 平台库 `zt_platform` | Alembic | 全平台统一运营，Console 直接 CRUD |
| 埋点事件 | 平台库 `zt_platform` | Alembic | Console 需**跨租户聚合**，事件集中存储避免遍历几十个租户库 |

Client 端通过 `/api/client`（带登录态，天然携带 `tenant_code / user_id / phone`）读取 Banner 列表与上报事件，服务端写入平台库。

## 3. 数据表设计（平台库，`sys_` 前缀）

### 3.1 `sys_promotion_banner` — Banner 配置表

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK | 主键 |
| title | VARCHAR(100) | NOT NULL | 内部标题/运营备注名 |
| image_url | VARCHAR(500) | NOT NULL | 图片地址（走现有 `/api/console/file` 上传） |
| link_type | VARCHAR(16) | NOT NULL, default `none` | `none` 只看不跳 / `external` 外链 / `internal` 站内路由 |
| link_url | VARCHAR(500) | NULL | 跳转地址，`none` 时为空；`external` 仅允许 http/https |
| open_in_new_tab | TINYINT | default 1 | 外链是否新标签打开 |
| target_type | VARCHAR(16) | NOT NULL, default `all` | `all` 全部 / `version` 按版本 / `tenant` 指定租户 |
| target_values | JSON | NULL | 定向白名单：version_code 列表或 tenant_code 列表 |
| sort_order | INT | default 0 | 轮播排序，小在前 |
| status | VARCHAR(16) | NOT NULL, default `draft` | `draft` 草稿 / `published` 上线 / `offline` 下线 |
| start_at | DATETIME | NULL | 生效时间（NULL 不限） |
| end_at | DATETIME | NULL | 失效时间（NULL 不限） |
| remark | VARCHAR(255) | NULL | 备注 |
| created_by | BIGINT | NULL | 配置人 user_id |
| created_at / updated_at / is_deleted | | | 平台基类标准字段 |

**Client 可见判定**：`status='published'` 且 `is_deleted=0` 且 当前时间在 `[start_at, end_at]` 内 且 命中定向（`all`，或 `version` 命中租户当前版本，或 `tenant` 命中租户编码），按 `sort_order, id` 排序。

### 3.2 `sys_promotion_banner_event` — 埋点明细表

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | |
| banner_id | BIGINT | 索引 |
| tenant_code | VARCHAR(32) | 哪个租户 |
| user_id | BIGINT | 哪个用户 |
| user_phone | VARCHAR(20) | 冗余，便于 Console 直接展示 |
| event_type | VARCHAR(16) | `view` 曝光 / `click` 点击 |
| occurred_at | DATETIME | 发生时间 |
| user_agent | VARCHAR(255) NULL | 可选，排查用 |

索引：`idx_banner_event (banner_id, event_type, occurred_at)`、`idx_tenant_event (tenant_code, occurred_at)`。

### 3.3 `sys_promotion_banner_stat_daily` — 每日聚合表（Phase 2，暂不落地）

后续曝光量增大后引入，按 `banner_id + tenant_code + stat_date` 聚合 `view_pv/view_uv/click_pv/click_uv`，明细表设 TTL 归档，长期报表读聚合表。**MVP 阶段统计直接对 `sys_promotion_banner_event` 做 GROUP BY，不建此表。**

## 5. 前端方案

### 5.1 Client：`banner-card.vue` 改造

- `onMounted` 调 `GET /workbench/banner`，渲染真实图片轮播；无数据时**保留现有渐变占位兜底**。
- 曝光埋点：Banner 首次进入视口（或首次渲染）上报 `view`，同一用户对同一 banner **每日仅上报一次**（`localStorage` 去重键 `banner_view_{id}_{yyyymmdd}`）。
- 点击埋点：点击时先上报 `click`（用 `navigator.sendBeacon`/`fetch keepalive` 保证跳转不丢），再执行跳转（`external` → `window.open`/当前页；`internal` → `router.push`；`none` → 不跳）。
- 外链安全：仅允许 `http/https`。

### 5.2 Console：Banner 管理页

- 列表页 `views/promotion/banner/index.vue`：搜索 + 表格（缩略图、标题、跳转类型、定向、状态、排期、排序）+ 新建/编辑/上下线/删除。
- 编辑抽屉：图片上传、跳转配置、定向配置（版本多选/租户多选）、排期、排序。
- 统计抽屉/页：聚合卡片（曝光 PV/UV、点击 PV/UV、CTR）+ 按租户聚合表 + 用户级明细分页（可导出）。
- 菜单：`sys_menu` 新增 `app_type='platform'` 的「运营推广 → Banner 管理」，`component=/promotion/banner/index`。

## 6. 迁移与落地

- 平台库：新增 ORM 模型后执行 `make migrate-new-platform name="add promotion banner"`，人工 review 迁移文件，提交迁移 + snapshot。
