# 租户业务库（zt_biz_{code}）数据库设计

## 概述

每个企业客户拥有独立的业务数据库，存储该企业的用户、组织、车辆、驾驶员、运单等业务数据。

**数据库命名**：
- 开发环境：`zt_biz_{tenant_code}_ci`（如 `zt_biz_1001_ci`）
- 生产环境：`zt_biz_{tenant_code}`（如 `zt_biz_1001`）

## 表清单

> **菜单说明**：租户库**无** `biz_menu` 表。`biz_role_menu.menu_id` 引用**平台库**菜单主数据（如 `sys_menu`），与 `biz_role` 做多对多关联。

## 建表 SQL

- 分表脚本：本目录 **`01`～`36` 号** `*.sql` 文件（与上表「SQL 文档」列一一对应）。
- 部署时通常由后端 SQLAlchemy ORM 执行建表（`metadata.create_all` 或迁移工具）；SQL 文件用于文档对齐与手工初始化场景。
- 已有租户库升级时，参见各 SQL 文件末尾的「升级脚本 vN」段（仅追加列与索引，不破坏存量数据）。

## 表关系说明

- `biz_user` 通过 `biz_user_role` 关联 `biz_role`（多对多）
- `biz_role` 通过 `biz_role_menu` 关联平台侧菜单 ID（多对多；菜单定义不在租户库）
- `biz_user.department_id` 关联 `biz_department`
- `biz_vehicle.trailer_id` 关联 `biz_trailer`（可选）
- `biz_vehicle_ext.vehicle_id` 关联 `biz_vehicle`（1:1 扩展）
- `biz_trailer_ext.trailer_id` 关联 `biz_trailer`（1:1 扩展）
- `biz_driver.user_id` 关联 `biz_user`
- `biz_driver_license.driver_id` 关联 `biz_driver`（1:1 资质信息）
- `biz_driver_operation.driver_id` 关联 `biz_driver`（1:1 运营属性）
- `biz_driver_operation.department_id` 关联 `biz_department`（所属车队）
- `biz_driver_account.driver_id` 关联 `biz_driver`（1:N 账户结算）
- `biz_driver_route.driver_id` 关联 `biz_driver`（1:N 常跑线路）
- `biz_dict_item.dict_id` 关联 `biz_dict`（字典项归属字典）
- `biz_vehicle_series.brand_id` 外键关联 `biz_vehicle_brand.brand_id`（车系归属品牌）
- `biz_waybill.customer_id` 关联 `biz_customer`（运单→客户）
- `biz_waybill_cargo.waybill_id` 关联 `biz_waybill`（运单货物明细→运单，1:N）
- `biz_waybill.contract_id` 关联 `biz_freight_contract`（运单→运价合同）
- `biz_waybill.rate_id` 关联 `biz_freight_rate`（运单→运价明细）
- `biz_freight_contract.customer_id` 关联 `biz_customer`（合同→客户）
- `biz_freight_rate.contract_id` 关联 `biz_freight_contract`（运价明细→合同）
- `biz_waybill.origin_region_id` / `destination_region_id` 关联 `biz_region.id`（运单线路→标准行政区）
- `biz_freight_rate.origin_region_id` / `destination_region_id` 关联 `biz_region.id`（运价线路→标准行政区）
- `biz_waybill_cargo.brand_id` / `series_id` 关联 `biz_vehicle_brand.brand_id` / `biz_vehicle_series.series_id`（货物→标准车型）
- `biz_freight_rate.brand_id` / `series_id` 关联 `biz_vehicle_brand.brand_id` / `biz_vehicle_series.series_id`（运价→标准车型）
- `biz_waybill.last_result_id` 关联 `biz_waybill_freight_result.id`（运单→当前生效的计算结果快照）
- `biz_waybill_freight_result_detail.result_id` 关联 `biz_waybill_freight_result.id`（计算结果明细→主表）
- `biz_waybill_freight_result_detail.waybill_cargo_id` 关联 `biz_waybill_cargo.id`（计算明细→货物明细）
- `biz_waybill_freight_result_detail.matched_rule_id` 关联 `biz_freight_rate.id`（计算明细→命中运价规则）
- `biz_waybill_freight_result_detail.matched_contract_id` 关联 `biz_freight_contract.id`（计算明细→命中合同）
- `biz_freight_calc_task.target_id` 视 `target_type` 关联运单/合同/规则/批次表
- `biz_freight_calc_exception.waybill_id` 关联 `biz_waybill.id`（异常→运单，可空）
- `biz_freight_calc_exception.batch_id` 关联 `biz_waybill_import_batch.id`（异常→导入批次，可空）
- `biz_region_alias.region_id` 关联 `biz_region.id`（别名→标准地区）
- `biz_vehicle_alias.brand_id` / `series_id` 关联 `biz_vehicle_brand.brand_id` / `biz_vehicle_series.series_id`
- `biz_freight_rate_change_log.rate_id` 关联 `biz_freight_rate.id`（变更日志→运价规则）
- `biz_waybill_import_row.batch_id` 关联 `biz_waybill_import_batch.id`（导入行→批次）
- `biz_waybill_import_row.waybill_id` 关联 `biz_waybill.id`（导入行→生成运单，导入成功后回填）

## 初始数据

新租户数据库创建时，自动插入以下初始数据（见各 SQL 或初始化脚本约定）：

- 默认角色：管理员（admin）、操作员（operator）、驾驶员（driver）
- 默认部门：总公司（HQ）→ 运营部（OP）/ 车队部（FL）/ 财务部（FI）
- 企业超管账号（由平台在创建租户时指定）
