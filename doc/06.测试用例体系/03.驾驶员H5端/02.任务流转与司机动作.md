# 任务流转与司机动作 测试用例

> **对应需求**：`doc/02.需求文档/03.移动端/02.驾驶员H5端/02.任务流转与司机动作.md`
> **对应后端**：`backend/app/modules/driver/api/task.py`、`services/driver_task_service.py`、`schemas/task.py`
> **对应前端**：`frontend/driver-h5/src/views/task`
> **测试脚本**：`backend/tests/driver/test_driver_task_service.py`、`test_driver_schemas.py`

## 接口清单

| 方法 | 路径 | 说明 | 状态推进 |
|---|---|---|---|
| GET | `/api/driver/task/my` | 我的任务分页 | - |
| GET | `/api/driver/task/{taskId}` | 任务详情 | - |
| POST | `/api/driver/task/{taskId}/accept` | 接收调令 | 写 `dispatch_order.accepted_at` |
| POST | `/api/driver/task/{taskId}/reject` | 拒绝调令 | task 1→0 |
| POST | `/api/driver/task/{taskId}/confirm-load` | 确认装车 | 聚合 1→2 |
| POST | `/api/driver/task/{taskId}/depart` | 确认出发 | 2→3 |
| POST | `/api/driver/task/{taskId}/confirm-arrive` | 确认到达 | 聚合 3→4 |
| POST | `/api/driver/task/items/{itemId}/sign` | 逐单签收 | item→3，聚合 4→5 |
| POST | `/api/driver/task/items/{itemId}/revert-sign` | 撤销签收（受限） | item 3→2，回退 5→4 |

## 测试用例

### TC-DRV-TASK-001 我的任务列表（空数据）
- **对应接口**：`GET /api/driver/task/my`
- **优先级**：P0 ｜ **类型**：正向/边界
- **前置条件**：新建司机、无任何关联任务
- **预期结果**：`{ list: [], total: 0 }`
- **自动化状态**：已覆盖脚本（`test_list_my_tasks_empty`）
- **执行结果**：❌ 失败（xfail）→ **BUG-DRV-001**（MySQL `NULLS LAST` 语法错误 500）

### TC-DRV-TASK-002 任务列表输出裁剪
- **对应接口**：`DriverTaskService._to_list_item`
- **优先级**：P1 ｜ **类型**：正向
- **预期结果**：`customerName=None`（司机端不下发客户名）；数值空值归零
- **自动化状态**：已覆盖脚本（`test_to_list_item_mapping`/`_none_numeric_defaults`）
- **执行结果**：✅ 通过

### TC-DRV-TASK-003 接收调令（仅"已派车"可接）
- **对应接口**：`POST /api/driver/task/{taskId}/accept`
- **优先级**：P0 ｜ **类型**：正向
- **前置条件**：task.status=1
- **预期结果**：全部调令 `accepted_at` 写当前时间；返回最新详情
- **自动化状态**：仅手工（需预置派车任务）
- **执行结果**：⬜ 未执行

### TC-DRV-TASK-004 接收调令 - 状态非法
- **对应接口**：`POST /api/driver/task/{taskId}/accept`
- **优先级**：P1 ｜ **类型**：反向
- **预期结果**：task.status≠1 → `BizException("仅「已派车」的任务可接收调令")`
- **自动化状态**：仅手工
- **执行结果**：⬜ 未执行

### TC-DRV-TASK-005 确认装车需先接单
- **对应接口**：`POST /api/driver/task/{taskId}/confirm-load`
- **优先级**：P0 ｜ **类型**：反向（业务前置）
- **预期结果**：无 `accepted_at` → `BizException("请先接收调令，再确认装车")`
- **自动化状态**：仅手工
- **执行结果**：⬜ 未执行

### TC-DRV-TASK-006 拒单原因必填
- **对应接口**：`POST /api/driver/task/{taskId}/reject`（`DriverRejectTaskRequest`）
- **优先级**：P1 ｜ **类型**：反向（参数校验）
- **测试数据**：`{}` / `{ reason: "" }`
- **预期结果**：HTTP 422（`reason` min_length=1）
- **自动化状态**：已覆盖脚本（`test_reject_reason_required`/`_empty_rejected`）
- **执行结果**：✅ 通过

### TC-DRV-TASK-007 装车照片数量与备注长度

- **自动化状态**：已覆盖脚本（`test_confirm_load_photo_max_9`/`_remark_max_255`）

- **优先级**：P0 ｜ **类型**：反向（数据隔离）

- **自动化状态**：已覆盖脚本（`test_visible_task_unknown_rejected`）
- **执行结果**：✅ 通过

### TC-DRV-TASK-009 接单不存在的任务

### TC-DRV-TASK-010 越权访问挂接行

- **优先级**：P0 ｜ **类型**：反向（数据隔离）
- **预期结果**：item 不存在或不属于本人任务 → `BizException`
- **自动化状态**：已覆盖脚本（`test_visible_item_unknown_rejected`）

### TC-DRV-TASK-011 全流程状态推进（装车→出发→到达→签收）
- **对应接口**：`confirm-load` → `depart` → `confirm-arrive` → `sign`
- **优先级**：P0 ｜ **类型**：正向（核心链路）
- **预期结果**：task 依次 1→2→3→4→5；末次签收聚合到 5
- **自动化状态**：仅手工（需完整派车+运单挂接数据）
- **执行结果**：⬜ 未执行

### TC-DRV-TASK-012 撤销签收受限
- **对应接口**：`POST /api/driver/task/items/{itemId}/revert-sign`
- **优先级**：P1 ｜ **类型**：反向（权限 + 状态）
- **预期结果**：仅 `item.status=3` 可撤；需权限 `operation:task:revert-sign`
- **自动化状态**：仅手工（需 HTTP 权限上下文）
- **执行结果**：❌ 权限未强制 → **BUG-DRV-003**

### TC-DRV-TASK-013 不允许跳跃/创建/派车
- **对应接口**：司机端全部
- **优先级**：P1 ｜ **类型**：反向（业务约束）
- **预期结果**：无创建任务/派车/跳跃推进接口；跳跃由状态机拒绝
- **自动化状态**：仅手工/设计核对
- **执行结果**：✅ 通过（接口层不存在写入口，符合需求）
