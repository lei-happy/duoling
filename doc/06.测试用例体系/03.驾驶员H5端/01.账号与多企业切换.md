# 账号体系与多企业切换 测试用例

> **对应需求**：`doc/02.需求文档/03.移动端/02.驾驶员H5端/01.账号体系与多企业切换.md`
> **对应后端**：`backend/app/modules/driver/api/auth.py`、`services/driver_auth_service.py`、`services/driver_context.py`
> **对应前端**：`frontend/driver-h5/src/views/login`、`tenant-select`
> **测试脚本**：`backend/tests/driver/test_driver_auth_service.py`、`test_driver_context.py`

## 接口清单

| 方法 | 路径 | 说明 | 认证角色 |
|---|---|---|---|
| POST | `/api/driver/auth/login` | 手机号+密码登录（强制 `user_type=3`） | 匿名 |
| POST | `/api/driver/auth/sms-login` | 手机号+验证码登录 | 匿名 |
| GET | `/api/driver/auth/user-tenants` | 可登录企业列表 | 司机 JWT |
| POST | `/api/driver/auth/switch-tenant` | 切换企业，重签 JWT | 司机 JWT |
| PUT | `/api/driver/auth/password` | 修改密码 | 司机 JWT |
| GET | `/api/driver/auth/user-info` | 司机信息+driverId | 司机 JWT |

## 测试用例

### TC-DRV-AUTH-001 密码登录（单企业直接下发 Token）
- **对应接口**：`POST /api/driver/auth/login`
- **优先级**：P0 ｜ **类型**：正向
- **前置条件**：存在 `user_type=3` 且仅关联 1 家有效企业的司机账号
- **测试步骤**：提交 `{ phone, password }`
- **预期结果**：HTTP 200，`code=0`，返回 `accessToken/refreshToken/user`，`user.userType=3`
- **自动化状态**：仅手工（正向依赖库内预置账号，脚本不做正向断言）
- **执行结果**：⬜ 未执行

### TC-DRV-AUTH-002 密码登录（多企业返回选择列表）
- **对应接口**：`POST /api/driver/auth/login`
- **优先级**：P0 ｜ **类型**：正向
- **前置条件**：同一手机号在 ≥2 家有效企业被开通为司机，登录不带 `tenant_code`
- **测试步骤**：提交 `{ phone, password }`（不带 `tenant_code`）
- **预期结果**：返回 `needSelectTenant=true` 与 `tenants[]`（仅 `user_type=3` 企业）
- **自动化状态**：仅手工
- **执行结果**：⬜ 未执行

### TC-DRV-AUTH-003 密码登录 - 手机号不存在
- **对应接口**：`POST /api/driver/auth/login`
- **优先级**：P1 ｜ **类型**：反向（业务校验）
- **测试步骤**：提交不存在的手机号
- **预期结果**：`AuthException("手机号或密码错误")`，不区分"账号不存在/密码错"
- **自动化状态**：已覆盖脚本（`test_login_unknown_phone_rejected`）
- **执行结果**：✅ 通过

### TC-DRV-AUTH-004 密码登录 - 密码错误
- **对应接口**：`POST /api/driver/auth/login`
- **优先级**：P1 ｜ **类型**：反向
- **预期结果**：`AuthException("手机号或密码错误")`
- **自动化状态**：仅手工（需预置真实账号）
- **执行结果**：⬜ 未执行

### TC-DRV-AUTH-005 非司机账号被拒（无 user_type=3 关联）
- **对应接口**：`POST /api/driver/auth/login`
- **优先级**：P0 ｜ **类型**：反向（权限隔离）
- **前置条件**：手机号仅在企业内是管理员/操作员（`user_type≠3`）
- **预期结果**：`AuthException("您还未被任何企业开通为驾驶员...")`
- **自动化状态**：仅手工
- **执行结果**：⬜ 未执行

### TC-DRV-AUTH-006 可登录企业列表（仅 user_type=3）
- **对应接口**：`GET /api/driver/auth/user-tenants`
- **优先级**：P1 ｜ **类型**：正向 + 边界
- **测试步骤**：未知 user_id 调用
- **预期结果**：返回空数组；有效企业需 `status=1` 且未过期
- **自动化状态**：已覆盖脚本（`test_list_tenants_unknown_user_empty`）
- **执行结果**：✅ 通过

### TC-DRV-AUTH-007 切换企业 - 无权企业被拒
- **对应接口**：`POST /api/driver/auth/switch-tenant`
- **优先级**：P0 ｜ **类型**：反向（权限）
- **测试步骤**：对未关联/未开通为司机的 `tenantCode` 切换
- **预期结果**：`AuthException`（用户不存在或无权访问该企业）
- **自动化状态**：已覆盖脚本（`test_switch_tenant_unknown_user_rejected`）
- **执行结果**：✅ 通过

### TC-DRV-AUTH-008 会话缺少企业上下文
- **对应接口**：所有 `/api/driver/*` 租户接口（经 `get_current_driver`）
- **优先级**：P1 ｜ **类型**：反向
- **测试步骤**：`TokenData.tenant_code=None`
- **预期结果**：`BizException("当前会话缺少企业上下文")`，触库前拒绝
- **自动化状态**：已覆盖脚本（`test_missing_tenant_code_rejected`）
- **执行结果**：✅ 通过

### TC-DRV-AUTH-009 非驾驶员 token 访问租户接口被拒
- **对应接口**：`get_current_driver`
- **优先级**：P0 ｜ **类型**：反向（权限）
- **测试步骤**：`TokenData.user_type=2`
- **预期结果**：`PermissionException("仅驾驶员账号可访问")`
- **自动化状态**：已覆盖脚本（`test_non_driver_user_type_rejected`）
- **执行结果**：✅ 通过

### TC-DRV-AUTH-010 司机档案锁定（user_id 命中）
- **对应接口**：`get_current_driver`
- **优先级**：P0 ｜ **类型**：正向
- **前置条件**：租户库存在 `biz_driver.user_id=当前用户` 且 `status=1`
- **预期结果**：返回 `DriverContext`，`driver_id` 正确
- **自动化状态**：已覆盖脚本（`test_resolve_by_user_id`）
- **执行结果**：✅ 通过（集成，DB 可连时）
