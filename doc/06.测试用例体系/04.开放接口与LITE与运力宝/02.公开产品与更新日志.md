# 公开产品版本 / 版本功能矩阵 / 更新日志 测试用例

> **对应需求**：`doc/02.需求文档/01.运营后台/09.产品管理`（开放侧公开查询）
> **对应后端**：`backend/app/modules/open/api/product.py`、`backend/app/modules/open/api/changelog.py`
> **对应前端**：`frontend/website`（官网价格 / 升级方案 / 更新记录页）
> **测试脚本**：`backend/tests/open/test_product_changelog.py`

## 接口清单

| 方法 | 路径 | 说明 | 认证角色 |
|---|---|---|---|
| GET | `/api/open/product/versions` | 产品版本列表（`status=1` 且未删除，按 sort_order） | 无 |
| GET | `/api/open/product/version-features` | 版本×功能矩阵（versions / modules / features） | 无 |
| GET | `/api/open/changelog` | 更新日志列表（仅已发布，分页） | 无 |

## 关键业务规则

- 版本列表仅返回启用中版本，含 versionCode / versionName / maxUsers / maxVehicles / price。
- 功能矩阵中每个 feature 的 `includedIn` 为其归属版本编码去重列表；`modules` 按出现次序去重。
- 更新日志分页 `page>=1`、`1<=page_size<=100`，仅返回 `status=1`（已发布）。
