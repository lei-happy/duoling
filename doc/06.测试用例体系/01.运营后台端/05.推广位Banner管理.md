# 推广位 Banner 管理 测试用例（Console）

> **对应需求**：`doc/02.需求文档/01.运营后台/11.推广Banner/01.首页推广位Banner管理.md`
> **对应后端**：`backend/app/modules/console/api/promotion/banner.py`、`services/promotion/banner_service.py`、`models/promotion/banner.py`
> **对应前端**：`frontend/console/src/views/promotion/banner`

## 接口清单

| 方法 | 路径 | 说明 | 认证角色 |
|---|---|---|---|
| GET | `/api/console/promotion/banner/page` | 分页查询 | 平台管理员 |
| GET | `/api/console/promotion/banner/{id}` | 详情 | 平台管理员 |
| POST | `/api/console/promotion/banner` | 新建（默认草稿） | 平台管理员 |
| PUT | `/api/console/promotion/banner/{id}` | 更新 | 平台管理员 |
| DELETE | `/api/console/promotion/banner/{id}` | 软删除 | 平台管理员 |
| POST | `/api/console/promotion/banner/{id}/publish` | 上线 | 平台管理员 |
| POST | `/api/console/promotion/banner/{id}/offline` | 下线 | 平台管理员 |
| GET | `/api/console/promotion/banner/{id}/stats` | 聚合统计（总览+按租户） | 平台管理员 |
| GET | `/api/console/promotion/banner/{id}/events` | 事件明细分页 | 平台管理员 |
| GET | `/api/console/promotion/banner/version-options` | 版本定向下拉 | 平台管理员 |
| GET | `/api/console/promotion/banner/tenant-options` | 租户定向下拉 | 平台管理员 |

### TC-CON-BANNER-001 新建 Banner（全部投放、只看不跳）

- **对应接口**：`POST /api/console/promotion/banner`
- **优先级**：P0 ｜ **用例类型**：正向
- **前置条件**：平台管理员登录；已上传得到图片 url
- **测试步骤**：提交 `title/image_url/link_type=none/target_type=all`

### TC-CON-BANNER-015 图片上传场景与尺寸提示（前端）

- **对应前端**：`views/promotion/banner/components/banner-edit.vue`
- **优先级**：P2 ｜ **用例类型**：正向 / 边界
- **测试步骤**：
  1. 上传宽高比接近 5:1 的图片 → 无警告，预览按 5:1 展示（`object-fit: cover` 不变形）
  2. 上传宽高比明显偏离（如 1:1）的图片 → 弹出「建议 1080×216」提示，但仍可上传
  3. 上传 >10MB → 报错拦截
- **预期结果**：与客户端展示区一致的比例预览；尺寸软校验与大小硬校验生效
- **自动化状态**：仅手工 ｜ **执行结果**：⬜ 未执行
