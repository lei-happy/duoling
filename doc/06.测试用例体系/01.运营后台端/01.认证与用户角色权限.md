# 认证与用户角色权限 测试用例

> **对应需求**：`doc/02.需求文档/01.运营后台/**`（登录认证 / 系统管理）
> **对应后端**：`backend/app/modules/console/api/auth/auth.py`、`system/user.py`、`system/role.py`
> **对应前端**：`frontend/console/src/views`（登录 / 用户 / 角色）
> **测试脚本**：`backend/tests/console/test_auth.py`、`test_system.py`

## 接口清单

| 方法 | 路径 | 说明 | 认证角色 |
|---|---|---|---|
| POST | `/api/console/auth/login` | 平台管理员账密登录 | 匿名 |
| POST | `/api/console/auth/refresh` | 刷新 Token | 匿名（需 refresh_token） |
| GET | `/api/console/auth/user-info` | 当前用户信息（角色+菜单） | 已登录 |
| PUT | `/api/console/auth/user-workplace-config` | 保存工作台配置 | 已登录 |
| PUT | `/api/console/auth/user-theme` | 保存主题配置 | 已登录 |
| GET/POST/PUT/DELETE | `/api/console/system/user*` | 用户 CRUD / 状态 / 查重 | 已登录 |
| GET/POST/PUT/DELETE | `/api/console/system/role*` | 角色 CRUD | 已登录 |

## 测试用例

### TC-CON-AUTH-001 access_token 签发与解析回环
- **对应接口**：`app.core.security.create_access_token / decode_access_token`
- **优先级**：P0 ｜**类型**：正向（纯逻辑）
- **前置条件**：无（零 DB）
- **测试步骤**：用管理员 TokenData 签发 access_token → 解析
- **预期结果**：解析出 user_id/phone/user_type/roles 与原始一致
- **自动化状态**：已覆盖脚本 ｜**执行结果**：✅ 通过

### TC-CON-AUTH-002 非法 token 解析返回 None
- **对应接口**：`decode_access_token`
- **优先级**：P1 ｜**类型**：反向 ｜**前置**：无
- **预期结果**：`"not-a-jwt"` / `""` 均返回 `None`，不抛异常
- **自动化状态**：已覆盖脚本 ｜**执行结果**：✅ 通过

### TC-CON-AUTH-003 refresh_token 不得被 access 解析接受
- **优先级**：P1 ｜**类型**：反向（安全）
- **预期结果**：`decode_access_token(refresh)` 返回 `None`；`decode_refresh_token` 正常
- **自动化状态**：已覆盖脚本 ｜**执行结果**：✅ 通过

### TC-CON-AUTH-004 ~ 006 工作台配置校验（纯逻辑）
- **对应接口**：`AuthService._validate_workplace_config`
- **优先级**：P2 ｜**类型**：正向 + 反向（边界）
- **测试数据/预期**：
  - None → 通过；`{version:1, quickActions:[...]}` → 通过
  - `quickActions` 非数组 → 抛 `AuthException`
  - `quickActions` > 16 项 → 抛 `BizException`
  - 元素为空串 → 抛 `AuthException`
- **自动化状态**：已覆盖脚本 ｜**执行结果**：✅ 通过

### TC-CON-AUTH-007 管理员登录成功
- **对应接口**：`POST /api/console/auth/login`
- **优先级**：P0 ｜**类型**：正向
- **前置条件**：平台库已 seed 管理员 `13800000000/admin123`
- **测试数据**：`{"phone":"13800000000","password":"admin123"}`
- **预期结果**：HTTP 200，`code=0`，返回 `access_token`、`refresh_token`，`user.user_type=0`
- **自动化状态**：已覆盖脚本 ｜**执行结果**：✅ 通过

### TC-CON-AUTH-008 密码错误
