# 租户与产品授权 测试用例

> **对应需求**：`doc/02.需求文档/01.运营后台/**`（租户/客户管理、产品版本授权）
> **对应后端**：`backend/app/modules/console/api/tenant/tenant.py`、`product/product_version.py`
> **对应前端**：`frontend/console/src/views`（客户管理 / 产品版本）
> **测试脚本**：`backend/tests/console/test_tenant_product.py`

## 接口清单

| 方法 | 路径 | 说明 | 认证角色 |
|---|---|---|---|
| GET | `/api/console/tenant/page` | 分页查询租户 | 已登录 |
| GET | `/api/console/tenant/stats` | 生命周期统计 | 已登录 |
| GET | `/api/console/tenant/{id}` | 租户详情 | 已登录 |
| POST/PUT | `/api/console/tenant` | 创建/更新租户 | 已登录 |
| GET | `/api/console/tenant/{id}/products` | 授权产品列表 | 已登录 |
| POST/DELETE | `/api/console/tenant/{id}/products*` | 开通/取消授权 | 已登录 |
| GET | `/api/console/product-version` | 版本分页 | 已登录 |
| GET | `/api/console/product-version/{id}` | 版本详情 | 已登录 |
| POST/PUT/DELETE | `/api/console/product-version*` | 版本 CRUD | 已登录 |

> **测试策略说明**：租户「创建」会调用 `db_manager.create_tenant_database` 建真实租户库（**不可事务回滚**），故本轮不通过 HTTP 创建租户，仅覆盖读接口与鉴权；产品版本 CRUD 仅写平台库 `sys_product_version`，可安全回滚。

- **预期结果**：HTTP 200，`code=0`，`data.list` 存在
- **执行结果**：✅ 通过

### TC-CON-PRODUCT-002 新增产品版本（关联 BUG-CON-001）
- **对应接口**：`POST /api/console/product-version` ｜P0 ｜正向
- **测试数据**：`{"version_code":"test_ver_xxx","version_name":"自动化测试版本","sort_order":999}`
- **预期结果（期望）**：HTTP 200，`code=0`，返回新版本 `id`
- **实际结果**：HTTP 500 —— 响应体 `ProductVersionOut.model_validate(version)` 访问未加载的 `created_at/updated_at`，触发 SQLAlchemy 懒加载（`MissingGreenlet`）→ 见 **BUG-CON-001**
- **自动化状态**：已覆盖脚本（`@xfail` 标记） ｜**执行结果**：❌ 阻塞（XFAIL，关联 BUG-CON-001）

### TC-CON-PRODUCT-003 创建产品版本当前行为回归护栏
- **对应接口**：`POST /api/console/product-version` ｜P1 ｜反向（回归护栏）
- **预期结果**：断言当前实际返回 HTTP 500 / `code=500`；修复 BUG-CON-001 后该护栏会失败，提示同步移除 TC-CON-PRODUCT-002 的 xfail
- **自动化状态**：已覆盖脚本 ｜**执行结果**：✅ 通过

### TC-CON-PRODUCT-004 查询不存在版本
