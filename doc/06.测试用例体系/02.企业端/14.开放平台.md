# 开放平台 测试用例与测试报告

> **对应后端（控制面）**：`backend/app/modules/open_platform/management/api.py`、`services/*`
> **对应后端（数据面）**：`backend/app/modules/open_platform/dataplane/*`、`security/*`、`capabilities/*`、独立入口 `backend/app/open_main.py`
> **对应前端**：`frontend/client/src/views/open-platform/**`、`frontend/client/src/api/open-platform/**`
> **测试脚本**：`backend/tests/open/test_open_platform_security.py`、`test_open_platform_registry.py`、`test_open_platform_management.py`
> **产品版本**：`open_platform` 功能已绑定全部版本（lite / ylb / standard / pro）

## 模块定位

开放平台面向租户，提供两类对外能力：

1. **API 接口**：给客户自有系统（ERP/TMS 等）对接，HMAC-SHA256 签名鉴权，走独立数据面 `/openapi/v1/*`。
2. **远程 MCP 服务**：给 AI 办公工具（Trae、WorkBuddy 等）对接，Bearer Token 鉴权，走 `/mcp/{slug}`（JSON-RPC 2.0 over HTTP）。

控制面（管理密钥/MCP/能力/审计）复用企业端 `/api/client/open-platform`；数据面单独进程 `zhitu-openapi` 部署，避免与业务接口抢资源。

## 接口清单

### 控制面（企业端 JWT + RBAC，功能门控 `open_platform`）

| 方法 | 路径（前缀 `/api/client/open-platform`） | 说明 |
|---|---|---|
| GET | `/capabilities` | 能力目录（读代码注册表） |
| GET | `/apps` | 接入应用列表（含有效密钥计数） |
| POST | `/apps` | 新建接入应用 |
| PUT | `/apps/{app_id}` | 编辑 / 启停应用 |
| GET | `/apps/{app_id}/credentials` | 应用下 API 密钥列表 |
| POST | `/apps/{app_id}/credentials` | 签发 API 密钥（明文仅返回一次） |
| PUT | `/credentials/{id}/scope` | 调整密钥可用能力 / IP 白名单 |
| POST | `/credentials/{id}/reset` | 重置密钥（旧密钥立即失效） |
| POST | `/credentials/{id}/revoke` | 停用密钥 |
| GET | `/apps/{app_id}/mcp` | MCP 连接列表 |
| POST | `/apps/{app_id}/mcp` | 新建 MCP 连接（返回一次性 Token 与配置） |
| PUT | `/mcp/{config_id}` | 编辑 MCP 连接（改名不动 slug/token） |
| DELETE | `/mcp/{config_id}` | 删除 MCP 连接（关联 Token 立即失效） |
| GET | `/logs` | 调用记录分页（`page` + `limit`，返回 `{list,count}`） |
| GET | `/logs/stats` | 调用概览统计 |

### 数据面（独立鉴权，`TenantMiddleware` 放行）

| 方法 | 路径 | 说明 | 鉴权 |
|---|---|---|---|
| GET | `/openapi/v1/_meta/capabilities` | 当前密钥可用能力 | HMAC 签名 |
| POST | `/openapi/v1/{capability_code}` | 调用能力 | HMAC 签名 |
| POST | `/mcp/{slug}` | 远程 MCP（JSON-RPC） | Bearer Token |

- **缺陷与修复（本轮发现）**

| 编号 | 现象 | 根因 | 修复 |

- **结论**：核心安全与业务逻辑用例全部通过；数据面端到端用例待联调环境补充（见第四节）。
