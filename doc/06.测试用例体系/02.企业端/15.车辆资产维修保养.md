# 车辆资产 · 维修保养 测试用例

> **对应需求**：`doc/02.需求文档/02.企业端/14.车辆资产模块/`
> **对应后端**：`backend/app/modules/client/api/capacity/maintenance/`、`services/capacity/maintenance/`
> **对应前端**：`frontend/client/src/views/capacity/maintenance/`
> **测试脚本**：`backend/tests/client/test_fleet_maintenance_service.py`
> **feature**：`fleet_maintenance`（仅 pro）

## 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/client/capacity/maintenance/board` | 维保看板 |
| GET/POST | `/api/client/capacity/maintenance/work-orders` | 工单分页 / 创建 |
| GET/PUT | `/api/client/capacity/maintenance/work-orders/{id}` | 详情 / 编辑草稿 |
| POST | `.../work-orders/{id}/start` | 开工（联动车辆/运力） |
| POST | `.../work-orders/{id}/complete` | 完工 |
| POST | `.../work-orders/{id}/cancel` | 取消 |
| GET/POST | `/api/client/capacity/maintenance/plans` | 保养计划分页 / 创建 |
| PUT/DELETE | `.../plans/{id}` | 编辑 / 删除 |
| POST | `.../plans/{id}/generate-work-order` | 由计划生成工单 |

## 二、工单与状态联动

### TC-CLI-FLEETMAINT-001 创建维修草稿
- **对应接口**：`POST .../work-orders`
- **优先级**：P0 ｜ **类型**：正向
- **预期**：`status=draft`，工单号 `WOyyyyMMdd####`
- **自动化状态**：已覆盖脚本 ｜ **执行结果**：见测试报告

### TC-CLI-FLEETMAINT-003 开工联动车辆与运力
- **对应接口**：`POST .../start`
- **优先级**：P0 ｜ **类型**：正向
- **前置**：车辆正常；绑定运力可接单
- **预期**：车辆 `status=2`/`status_source=maintenance`；运力 `operation_status=5`；工单 `in_progress`
- **自动化状态**：已覆盖脚本 ｜ **执行结果**：见测试报告

### TC-CLI-FLEETMAINT-004 运输中禁止开工
- **对应接口**：`POST .../start`
- **优先级**：P0 ｜ **类型**：反向
- **前置**：运力 `operation_status=2`
- **预期**：`BizException` 含「运输任务尚未结束」
- **自动化状态**：已覆盖脚本 ｜ **执行结果**：见测试报告

### TC-CLI-FLEETMAINT-005 完工回落
- **对应接口**：`POST .../complete`
- **优先级**：P0 ｜ **类型**：正向
- **预期**：车辆恢复正常；运力恢复可接单；工单 `completed`
- **自动化状态**：已覆盖脚本 ｜ **执行结果**：见测试报告

### TC-CLI-FLEETMAINT-006 取消进行中工单释放占用
- **对应接口**：`POST .../cancel`
- **优先级**：P1 ｜ **类型**：正向
- **预期**：与完工相同释放车辆/运力
- **自动化状态**：手工/可扩脚本 ｜ **执行结果**：待测

### TC-CLI-FLEETMAINT-007 同车第二张进行中工单拒绝
- **优先级**：P0 ｜ **类型**：反向
- **预期**：`BizException` 含「进行中的维保工单」
