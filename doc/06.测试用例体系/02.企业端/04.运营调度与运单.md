# 运营调度与运单 测试用例

> **对应需求**：`doc/02.需求文档/02.企业端/06.运营调度模块/**`
> **对应后端**：`backend/app/modules/client/api/task/**`、`api/waybill/**`、`services/state_machine/**`
> **对应前端**：`frontend/client/src/views/business`

>（状态机穷举矩阵见根目录 `backend/tests/test_state_machines.py`）

## 接口清单（节选）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST/PUT/DELETE | `/api/client/business/waybill` | 运单管理 V2 |
| GET/POST | `/api/client/business/task` | 运输任务单（调度） |
| GET/POST | `/api/client/business/task-finance` | 任务单财务费用 |

## 状态机模型

- **Task**：`-1/0/1/2/3/4/5/7/9`（草稿→待派→已派→装车中→运输中→部分/已签收→已关闭→取消）
- **Item**（任务-运单挂接明细）：`0/1/2/3/9`，由 Task 状态派生聚合
- **Waybill**：`0~7`，多任务并发装车时可跨步聚合推进
