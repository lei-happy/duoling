# 能源中心 测试用例

> **对应需求**：`doc/02.需求文档/02.企业端/15.能源中心/01.产品方案与功能设计.md`
> **对应后端**：`backend/app/modules/client/{api,services,models}/energy/`
> **对应前端**：`frontend/client/src/views/energy/`
> **测试脚本**：
> - `backend/tests/client/test_energy_masterdata.py`
> - `backend/tests/client/test_energy_account_flow.py`
> - `backend/tests/client/test_energy_consumption_flow.py`
> - `backend/tests/client/test_energy_ledger.py`
> - `backend/tests/client/test_energy_pipeline.py`

主路径：供应商/站点 → 商品/档案 → 账户 → 卡绑定 → 充值入账 → 消费入账 → 对账/分析。

## 接口清单（闭环相关）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/client/energy/suppliers` | 新增供应商 |
| POST | `/api/client/energy/stations` | 新增站点 |
| POST | `/api/client/energy/products` | 新增商品 |
| POST | `/api/client/energy/vehicle-profiles` | 保存车辆档案 |
| GET | `/api/client/energy/rules` | 风控规则（空则种子化） |
| POST | `/api/client/energy/accounts` | 开账户 |
| POST | `/api/client/energy/cards` | 发卡 |
| POST | `/api/client/energy/cards/{id}/bind` | 绑定车辆/司机 |
| POST | `/api/client/energy/recharges` | 充值草稿 |
| POST | `/api/client/energy/recharges/{id}/pay` | 登记付款入账 |
| POST | `/api/client/energy/consumptions` | 手工消费 |
| POST | `/api/client/energy/connectors/{id}/import` | Excel 导入 |
| POST | `/api/client/energy/recons/balance` | 余额对账 |
| GET | `/api/client/energy/analysis/overview` | 分析概览 |

## 测试用例

### TC-CLI-ENERGY-001 新增供应商后可序列化 Out

- **对应接口**：`POST /api/client/energy/suppliers`
- **优先级**：P0
- **用例类型**：正向
- **预期结果**：自动生成 `ES` 编码，`createdAt` 非空，不触发异步懒加载
- **自动化状态**：已覆盖脚本
- **执行结果**：通过（BUG-CLI-ENERGY-001）

### TC-CLI-ENERGY-002 供应商空名称 / 编码冲突 / 软删复用

- **对应接口**：`POST /api/client/energy/suppliers`
- **优先级**：P0
- **用例类型**：反向
- **预期结果**：`BizException`，不出现 IntegrityError
- **自动化状态**：已覆盖脚本
- **执行结果**：通过

### TC-CLI-ENERGY-010 站点 CRUD 与供应商校验

- **对应接口**：`POST/PUT/DELETE /api/client/energy/stations`
- **优先级**：P0
- **预期结果**：供应商不存在、编码重复、空字段均友好报错
- **自动化状态**：已覆盖脚本
- **执行结果**：通过

### TC-CLI-ENERGY-012 站点位置与结算价

- **对应接口**：`POST/PUT /api/client/energy/stations`
- **优先级**：P0
- **预期结果**：可写经纬度；按能源类型维护当前结算价；按能源筛选站点
- **自动化状态**：已覆盖脚本
- **执行结果**：通过

### TC-CLI-ENERGY-015 商品 / 车辆档案 / 风控规则种子

- **对应接口**：`/energy/products` `/energy/vehicle-profiles` `/energy/rules`

### TC-CLI-ENERGY-021 开账户 / 发卡绑定 / 充值入账
