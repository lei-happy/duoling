## 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/client/capacity/self_capacity/group` | 分组分页列表（含 memberCount） |
| GET | `/api/client/capacity/self_capacity/group/options` | 启用分组精简列表（成本规则条件下拉） |
| POST | `/api/client/capacity/self_capacity/group` | 新建分组 |
| PUT | `/api/client/capacity/self_capacity/group/{id}` | 编辑分组 |

| DELETE | `/api/client/capacity/self_capacity/group/{id}` | 删除分组（连带软删成员） |
| GET | `/api/client/capacity/self_capacity/group/{id}/members` | 分组成员分页 |
| POST | `/api/client/capacity/self_capacity/group/{id}/members` | 批量添加成员（传运力ID） |
| DELETE | `/api/client/capacity/self_capacity/group/{id}/members` | 批量移出成员 |
