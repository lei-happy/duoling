# 只读检查弹框规范

> **适用范围**：企业端 Client（`frontend/client`）里「查看一条业务对象」的只读弹层。  
> **目的**：统一只读详情的容器、材质、动效、信息结构和标识复制，避免各模块各写一套抽屉 / 默认 Dialog。  
> **参考实现**  
> - 壳：`frontend/client/src/components/InspectDialog/`  
> - 范例：计划详情 / 商品车明细 / 关联任务 / 计算明细  
>   `frontend/client/src/views/operation/waybill/components/waybill-detail.vue`  
>   `frontend/client/src/views/operation/waybill/components/waybill-cargoes-detail.vue`  
>   `frontend/client/src/views/operation/waybill/components/waybill-task-items-detail.vue`  
>   `frontend/client/src/views/operation/waybill/components/waybill-freight-detail.vue`

---

## 1. 总则

### 1.1 什么时候用 InspectDialog

用户要**看完一份单据再回去继续列表工作**时，用居中检查弹框，不用右侧抽屉。

典型场景：

- 计划详情、商品车明细、调度占用、运费计算明细
- 任务 / 合同 / 司机等对象的只读摘要
- 从列表数字、状态点进去的「展开看清楚」

### 1.2 什么时候不用

| 场景 | 用什么 | 原因 |
|---|---|---|
| 新增 / 编辑（有表单、分步、校验） | 现有 `el-dialog`（如计划编辑） | 检查弹框是只读阅读器，不是表单壳 |
| 不可逆确认（删除、锁定） | `ElMessageBox` | 决策要短，不要铺成详情 |
| 超长流水 / 导入批次对照 | 可以继续用抽屉 | 需要占满半屏纵向扫描；新功能仍优先评估检查弹框是否够用 |

**禁止**：同一列表里，有的只读入口是毛玻璃检查弹框，有的仍是默认 Element 对话框或抽屉。同一工作台的只读入口必须同一套壳。

### 1.3 交互原则

- **聚焦**：遮罩压暗并轻微模糊背景，弹框居中，点遮罩或右上角关闭可退出。
- **空间一致**：进入、退出沿同一条路径（轻微放大 + 上移），不要滑入右侧再向下消失。
- **按下去才有反馈**：关闭按钮、复制按钮、页脚按钮在 `active` 时立刻缩小，不要等 `click` 才变。
- **标识可带走**：计划号、VIN、任务单号等要复制的字段，必须有复制按钮，成功/失败用口语 Toast。
- **尊重系统偏好**：`prefers-reduced-motion` 改为短淡入淡出；`prefers-reduced-transparency` 取消毛玻璃，顶栏/页脚改为实色白底。

## 2. 视觉标准

弹框不是又一张后台表单，而是一张「单据」。第一眼应能读出：**这是谁的、从哪到哪、有多少台 / 多少钱**。

### 2.1 材质与层级

| 角色 | 做法 | 不要 |
|---|---|---|
| 遮罩 | 半透明黑 + `backdrop-filter` 模糊 | 纯黑实底、无聚焦感 |
| 顶栏 / 页脚 | 半透明白 + 模糊，内容在底下滚 | 不透明色条硬切、1px 深色分割线当主分隔 |
| 画布 | `#F5F5F7` | 整页纯白铺满 |
| 内容块 | 白底、12px 圆角、浅分割 | 大渐变卡片、重阴影、发光边 |

圆角：外壳 16px，内块 12px。阴影只用一层轻投影托起弹框，内容块最多 1px 浅线。

### 2.2 信息结构（固定顺序）

```text
┌ 顶栏：标题 + 可复制单号 + 状态标签     [×] ┐
│                                              │
│  摘要区（线路轴 / 金额）                      │
│  分组清单（字段行）                           │
│  明细列表（商品车 / 任务卡 / 表格）           │
│                                              │
└ 页脚：关闭（次要）  主操作（如有，如重算）    ┘
```

- **摘要区**用 `wbi-hero`：客户（或结果名）+ 起运 / 送达轴线 + 右侧圆形数量章（台数 / 已调）或大号金额。
- **分组清单**用 `wbi-section` + `wbi-group` + `wbi-row`，不要再堆 `el-descriptions` / `el-divider`。
- **商品车**用 `wbi-vehicle`（车系图 + 品牌车型 + VIN）。
- **关联对象**用 `wbi-card`（单号 + 复制 + 状态 + 占用说明）。
- 宽表（如计算明细）可以留在分组里用 `el-table`，但外壳仍是这套弹框。

### 2.3 文案

- 本系统承运对象是**商品车**，用户可见文案禁止写「货物」。
- 数量单位用「台」，不要用「件数 / 货量」。
- 空态说人话：「暂无商品车明细」「没有找到这份计划」，不要「暂无数据」。
- 页脚只读弹框的关闭用默认按钮，**不要**把「关闭」做成主色实心按钮；主色留给「立即重算」这类动作。

### 2.4 动效（已做在壳里，业务页不要另写一套）

- 进入：约 400ms，`cubic-bezier(0.32, 0.72, 0, 1)`，`scale(0.96)` + 下移 8px → 原位。
- 离开：沿原路回去，约 280ms。
- 减少动效：200ms 透明度交叉淡化，去掉位移和缩放。

## 3. 标准写法

### 3.1 引用

```ts
import InspectDialog from '@/components/InspectDialog/index.vue';
import InspectCopyButton from '@/components/InspectDialog/copy-button.vue';
```

也可：

```ts
import {
  InspectDialog,
  InspectCopyButton,
  copyTextWithToast
} from '@/components/InspectDialog';
```

### 3.2 最小模板

```vue
<inspect-dialog
  :visible="visible"
  title="计划详情"
  :subtitle="waybillNo"
  :copyable-subtitle="!!waybillNo"
  copy-subtitle-success="已复制计划号"
  copy-subtitle-empty="无可复制的计划号"
  copy-subtitle-label="复制计划号"
  :loading="loading"
  width="760px"
  @update:visible="onVisible"
>
  <section class="wbi-hero" aria-label="线路摘要">
    <!-- 客户 + 起运/送达 + 台数章 -->
  </section>
  <section class="wbi-section">
    <h3 class="wbi-section__title">计划信息</h3>
    <div class="wbi-group">
      <div class="wbi-row">
        <span class="wbi-row__label">要求送达</span>
        <span class="wbi-row__value">{{ deliverAt }}</span>
      </div>
    </div>
  </section>

  <template #footer>
    <el-button @click="onVisible(false)">关闭</el-button>
  </template>
</inspect-dialog>
```

### 3.3 常用 props

| Prop | 说明 |
|---|---|
| `visible` | 显隐，配合 `update:visible` |
| `title` | 顶栏标题，如「计划详情」 |
| `subtitle` | 等宽字体的业务单号 |
| `copyableSubtitle` | 单号旁显示复制。汇总文案（「3 张计划」）必须关 |
| `copySubtitleSuccess` / `Empty` / `Label` | 复制成功、空值、无障碍文案，写具体对象名 |
| `loading` | 壳内 `v-loading` |
| `width` | 默认 `760px`；明细表可到 `920px`。壳已限制 `max-width: calc(100vw - 32px)` |
| `header-extra` | 状态标签等，放在单号右侧 |

### 3.4 内容 class（壳已提供，勿再复制一份 CSS）

| Class | 用途 |
|---|---|
| `wbi-hero` / `wbi-hero--freight` | 线路摘要 / 金额摘要 |
| `wbi-section` + `wbi-section__title` | 分组标题 |
| `wbi-group` + `wbi-row` | 字段清单 |
| `wbi-vehicle` | 商品车行 |
| `wbi-card` / `wbi-chip-row` | 关联任务卡、占用明细行 |
| `wbi-note` | 浅色说明，替代打断阅读的大 Alert（确有风险时仍可用 `el-alert`） |

class 前缀 `wbi-` 来自最早的计划检查弹框，现作为全系统只读检查弹框的标记，**不要**在业务页另起 `xxx-dialog` 皮肤覆盖顶栏。

## 4. 标识复制

计划号、VIN、任务单号、车牌等**要拿去别处搜或发给同事**的字段，必须可一键复制。

1. 顶栏单号：`copyable-subtitle`。
2. 正文标识：`<inspect-copy-button :text="vin" success-tip="已复制 VIN" … />`。
3. 列表单元格等非弹框场景：调用 `copyTextWithToast`，Toast 文案仍写「已复制计划号」而不是「复制成功」。
4. 复制按钮用 `wbi-copy` 的圆形轻按钮，不要再手写一排 `el-button link`。
5. 失败提示：「复制失败，请重试」。空值：「无可复制的计划号 / VIN」。

汇总型副标题（多计划合并、「任务 xxx」占位）**不要**开复制，避免把说明文字写进剪贴板。

---

## 5. 存量与新功能

- **新功能**：只读查看一律走 `InspectDialog`，对照计划列表四套弹框实现。
- **存量**：同一页面若已有一只检查弹框，其余只读入口必须改过来，禁止混用默认 Dialog / Drawer。
- **跨页复用**：像商品车明细这种已被任务台账引用的组件，改壳即可两处一起对齐，不要再分叉一套皮肤。

## 6. 自检

打开弹框后快速看这几项：

1. 遮罩是否压暗且顶栏有毛玻璃（系统未开「减少透明度」时）？
2. 标题下是否有单号，计划号 / VIN 能否复制？
3. 摘要是不是线路或金额，而不是又一张 descriptions 表？
4. 关闭是次要按钮，主操作才用主色？
5. 文案有没有漏网的「货物」？
6. 与同页其它只读弹框是否同一套壳，而不是「一个新、一个旧」？
