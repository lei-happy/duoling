# 快捷操作 — 接入说明

## 1. 模块定位

- **展示位置**：客户端「今日工作台」(`/dashboard/workplace`) 顶部快捷操作区。
- **配置方式**：由 Console 运营在「系统管理 → 客户端菜单」中，对具体菜单/按钮开启"支持快捷操作"并上传专属图标。**无需改前端代码**。
- **目录下发**：`GET /api/client/workbench/quick-action`（后端读取 `sys_menu.quick_action` 非空的 client 菜单）。
- **运行时逻辑**：`use-quick-actions.ts`（权限过滤、排序、服务端持久化）。
- **用户个人选择持久化**：`sys_user.workplace_config`，API `PUT /auth/user-workplace-config`。

数据流：

```
Console 客户端菜单编辑(开关+图标)  ->  sys_menu.quick_action (JSON)
        ->  GET /workbench/quick-action  ->  前端注册表(接口驱动)
        ->  按用户权限(menu_code) + 产品功能(feature_code)过滤后展示
用户勾选/排序  ->  workplace_config.quickActions (key = menu_code)
```

## 2. `key` 与存储

- 快捷操作的 `key` = 该菜单的 **权限标识 `menu_code`**（如 `business:waybill:add`）。
- 用户已选项存 `workplace_config.quickActions`（key 数组，最多 12 项）。
- 历史遗留的旧 key（如 `waybill.create`）由前端 `normalizeQuickActionKey` 自动映射为新 `menu_code`，无需手动迁移。

## 3. 接入步骤（运营侧，Console）

1. 进入「系统管理 → 客户端菜单」，编辑目标菜单或按钮。
2. 打开「快捷操作」开关。
3. 上传「专属图标」（scene=`quick_action`，建议正方形 PNG，≤2MB）。
4. 按需填写：
   - 显示名称：默认使用菜单名称。
   - 图标底色：图标区背景色。
   - 跳转链接：默认使用菜单路由地址；"新建"类入口可带参数，如 `/operation/waybill?action=create`。
   - 分组名称：管理弹窗内分组标题，默认取所属顶级菜单。
   - 排序号 / 默认展示：排序权重与新用户是否默认展示。
5. 保存后，持有相关功能的租户 `menu_version` 自动递增（如经产品功能/授权变更），客户端切换路由时自动刷新目录。

## 4. `sys_menu.quick_action` 字段结构（JSON）

| 字段 | 说明 |
|------|------|
| `icon` | 专属图标 URL（上传返回的 `/uploads/quick_action/...`） |
| `name` | 显示名称（空则用 `menu_name`） |
| `color` | 图标底色 |
| `link` | 跳转链接（空则用 `path`，可带 query） |
| `group` | 管理弹窗分组（空则回退顶级菜单名） |
| `sort` | 排序权重（越小越靠前） |
| `default` | 新用户默认展示 |

`quick_action` 为 `NULL` 表示该菜单不支持快捷操作。

## 5. 权限与功能码

- **可见性**：快捷操作按其菜单 `menu_code` 做 RBAC 校验（用户有该权限才可添加），并按 `feature_code` 做产品版本门控（`hasFeature`）。
- **按钮级入口**（如「新建运单」）：直接在对应按钮（如 `business:waybill:add`）上开启快捷操作，并用「跳转链接」指向列表页 + `?action=create`。
- **列表页入口**（如「运单管理」）：在列表菜单（如 `business:waybill:list`）上开启即可。

## 6. "新建"类入口：目标页支持 query

若快捷操作需打开目标页的创建弹层，推荐：

1. 「跳转链接」指向列表页并带 `?action=create`；
2. 目标页 `onMounted` 检测 `route.query.action === 'create'` 后打开弹层，并 `router.replace` 清除 query。

参考实现：`frontend/client/src/views/operation/waybill/index.vue`。

## 7. 图标渲染

- 前端优先渲染上传的 `image`（图标 URL）；未配置图标时使用占位图标兜底。

## 8. 存量数据回填

改造上线后，如需保留原 9 个默认快捷操作，执行一次性脚本（仅回填未配置的菜单，图标待运营上传）：

```bash
python backend/scripts/fix/seed_quick_actions.py --dry-run   # 预览
python backend/scripts/fix/seed_quick_actions.py             # 执行
```

## 9. 测试清单

- [ ] Console 开启快捷操作并上传图标后，租户端「管理」弹窗出现该项、可添加/移除/排序。
- [ ] 有权限用户默认项正确展示，图标为上传图。
- [ ] 无权限 / 无对应 feature 的用户：对应项不在「可添加」列表，已选区不展示。
- [ ] 超过 12 项时前端提示，后端 PUT 拒绝非法数组长度。
- [ ] 配置变更后刷新页面、换浏览器，顺序与内容一致；不同账号互不影响。
- [ ] 历史 `workplace_config` 旧 key 能正确映射到新 `menu_code`。
- [ ] "新建"类入口跳转后自动打开新建弹层。
