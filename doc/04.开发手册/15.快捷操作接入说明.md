# 快捷操作 — 接入说明

## 1. 模块定位

- **展示位置**：客户端「今日工作台」(`/dashboard/workplace`) 顶部快捷操作区。
- **注册表路径**：`frontend/client/src/views/dashboard/workplace/quick-action/quick-action-registry.ts`
- **运行时逻辑**：`use-quick-actions.ts`（权限过滤、排序、服务端持久化）
- **持久化**：`sys_user.workplace_config`，API `PUT /auth/user-workplace-config`

新增业务入口时，**通常只需修改注册表 + 本文档事件清单**，无需改 UI 组件。

## 2. `key` 命名约定

- 格式：`域.动作`，全小写，分段用英文句点。
- 示例：
  - `waybill.create` — 新建运单
  - `task.create` — 新建配载
  - `waybill.list` — 运单管理列表

同一 `key` 全局唯一；重命名 key 时需编写迁移逻辑（见 `workplace_config.version`）。

## 3. 接入步骤

### 3.1 在注册表追加配置

编辑 `quick-action-registry.ts`，在 `QUICK_ACTION_REGISTRY` 数组末尾追加：

```typescript
{
  key: 'approval.pending',
  title: '待我审批',
  icon: 'MailOutlined',
  color: '#597ef7',
  group: '审批中心',
  type: 'route',
  path: '/approval/pending',
  permission: 'approval:pending:list',
  feature: 'biz_approval',        // 可选：产品功能码
  defaultVisible: false,          // 可选：新用户默认展示
  sortOrder: 100
}
```

### 3.2 注册图标组件

若使用新的图标名，在以下两个文件的 `defineOptions({ components: { ... } })` 中注册：

- `components/quick-action-bar.vue`
- `components/quick-action-picker.vue`

图标来自 `@/components/icons`（ele-admin-plus 图标集）。

### 3.3 「新建」类入口：目标页支持 query

若快捷操作需打开目标页的创建弹层，推荐：

1. `path` 指向列表页；
2. `query: { action: 'create' }`；
3. 目标页 `onMounted` 检测 `route.query.action === 'create'` 后打开弹层，并 `router.replace` 清除 query。

参考实现：`frontend/client/src/views/operation/waybill/index.vue`。

### 3.4 更新文档

在本节「已注册清单」中登记新 key，便于产品/测试对齐。

## 4. 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `key` | 是 | 全局唯一标识，写入服务端 |
| `title` | 是 | 卡片展示文案 |
| `icon` | 是 | 图标组件名 |
| `color` | 否 | 图标颜色 |
| `group` | 是 | 管理弹窗分组标题 |
| `type` | 是 | `route`（内部路由）或 `external`（外链） |
| `path` | 是 | 路由 path 或 URL |
| `query` | 否 | 路由 query 参数 |
| `permission` | 否* | RBAC 权限码，与 `sys_menu.menu_code` 对齐 |
| `feature` | 否 | 产品功能码，与 `hasFeature` 对齐 |
| `defaultVisible` | 否 | 新用户默认是否展示 |
| `sortOrder` | 否 | 默认排序权重 |

\* 若不填 `permission`，fallback 为检查 `path` 是否在用户菜单树中。

## 5. 权限与功能码

- **按钮级入口**（如「新建运单」）：填 `permission: 'business:waybill:add'`。
- **列表页入口**（如「运单管理」）：填 `permission: 'business:waybill:list'` 或对应菜单 `menu_code`。
- **产品版本门控**：填 `feature: 'biz_waybill'`，与租户 `features` 列表对齐。

用户「可添加」= 注册项通过 permission + feature 校验；已选但权限收回的项自动从展示栏隐藏。

## 6. 路由型 vs 外链型

| type | 行为 |
|------|------|
| `route` | 使用 `router-link` 跳转，`query` 可选 |
| `external` | 使用 `<a target="_blank">` 打开外链 |

首版不支持「直接在首页弹窗新建」；请通过路由 + query 触发目标页弹层。

## 8. 测试清单

- [ ] 有权限用户：默认项正确展示，「管理」中可添加/移除/排序。
- [ ] 无权限用户：对应项不在「可添加」列表，已选区不展示。
- [ ] 超过 12 项时前端提示，后端 PUT 拒绝非法数组长度。
- [ ] 配置变更后刷新页面、换浏览器，顺序与内容与上次一致。
- [ ] 不同账号配置互不影响。
- [ ] 「重置布局」恢复默认快捷操作。
- [ ] `waybill.create` 跳转后自动打开新建运单弹层。
