# 浮动标签组件集成指南

本文档介绍如何在筛选表单中使用浮动标签（Floating Label）组件，提升用户交互体验。

## 1. 组件概述

浮动标签组件是一个 Material Design 风格的输入组件，具有以下特点：

- **优雅的交互动画**：标签文字在输入框内外平滑过渡
- **节省空间**：初始状态标签在输入框内，激活后移至上方
- **状态智能识别**：自动识别聚焦、有值、禁用等状态
- **标签智能简化**：激活状态自动去除"请输入"、"请选择"等前缀，标签更简洁
- **支持多种类型**：支持普通输入框、日期选择器、下拉选择器
- **完美兼容 Element Plus**：基于 Element Plus 组件封装，保持一致的 UI 风格

### 1.1 交互效果

| 状态 | 效果说明 |
|------|----------|
| **初始状态** | 标签文字显示在输入框内部，显示完整文案如"请输入事件名称" |
| **聚焦状态** | 标签平滑移动到左上角，自动简化为"事件名称"（去除前缀），并变为主题色 |
| **有值状态** | 标签保持在上方，显示简化后的文案，颜色变为常规文字色 |
| **清除后** | 清空内容且失焦后，标签恢复到输入框内，显示完整文案 |

### 1.2 标签智能简化

组件会自动识别并去除以下常见前缀：

| 前缀 | 初始状态显示 | 激活状态显示 |
|------|-------------|-------------|
| `请输入` | 请输入事件名称 | 事件名称 |
| `请选择` | 请选择事件类型 | 事件类型 |
| `请填写` | 请填写手机号 | 手机号 |
| `请选择或输入` | 请选择或输入城市 | 城市 |

> 提示：如果标签不含上述前缀，则激活和初始状态显示相同的文案。

## 2. 项目配置

浮动标签组件位于 monorepo 的共享组件目录 `frontend/components/FloatingLabel/`，各子项目（console、client、template、website）通过 `@shared/` 路径别名引用。

> 如果你的子项目已完成以下配置，可跳过此章节。

### 2.1 Vite 别名配置

在子项目的 `vite.config.ts` 的 `alias` 中添加 `@shared/` 指向共享组件目录：

```typescript
import { resolve } from 'node:path';

// 在 alias 对象中添加
const alias = {
  '@/': resolve('src') + '/',
  '@shared/': resolve('../components') + '/',  // 共享组件
  // ... 其他别名
};
```

### 2.2 TypeScript 路径映射

在子项目的 `tsconfig.json` 中添加路径映射和文件包含：

```json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["src/*"],
      "@shared/*": ["../components/*"]
    }
  },
  "include": [
    "../components/**/*.ts",
    "../components/**/*.d.ts",
    "../components/**/*.vue",
    "src/**/*.ts",
    "src/**/*.d.ts",
    "src/**/*.vue"
  ]
}
```

## 3. 快速开始

### 3.1 导入组件

在 Vue 组件的 `<script>` 部分导入浮动标签组件：

```vue
<script lang="ts" setup>
  import FloatingLabel from '@shared/FloatingLabel/index.vue';
</script>
```

### 3.2 基本用法

#### 普通输入框

```vue
<template>
  <floating-label
    label="请输入用户账号"
    type="input"
    v-model="form.username"
    clearable
  />
</template>
```

#### 日期时间范围选择器

```vue
<template>
  <floating-label
    label="时间范围"
    type="date"
    date-type="datetimerange"
    v-model="dateRange"
    range-separator="-"
    value-format="YYYY-MM-DD HH:mm:ss"
    start-placeholder="开始时间"
    end-placeholder="结束时间"
    :unlink-panels="true"
    clearable
  />
</template>
```

#### 月份选择器

```vue
<template>
  <floating-label
    label="请选择月份"
    type="date"
    date-type="month"
    v-model="month"
    format="YYYY-MM"
    value-format="YYYY-MM"
    clearable
  />
</template>
```

#### 月份范围选择器

```vue
<template>
  <floating-label
    label="月份范围"
    type="date"
    date-type="monthrange"
    v-model="monthRange"
    format="YYYY-MM"
    value-format="YYYY-MM"
    range-separator="-"
    start-placeholder="开始月份"
    end-placeholder="结束月份"
    :unlink-panels="true"
    clearable
  />
</template>
```

#### 下拉选择器（单选）

```vue
<template>
  <floating-label
    label="请选择状态"
    type="select"
    v-model="form.status"
    clearable
  >
    <el-option label="开启" :value="0" />
    <el-option label="关闭" :value="1" />
  </floating-label>
</template>
```

#### 地区级联（el-cascader）

适用于省市区或导航树选择；`v-model` 与 `el-cascader` 一致（通常为选中路径数组）。

```vue
<template>
  <floating-label
    label="请选择出发地"
    type="cascader"
    v-model="originCodes"
    :cascader-options="regionTree"
    :cascader-option-props="cascaderProps"
    :cascader-filterable="true"
    @change="onOriginChange"
  />
</template>

<script setup lang="ts">
import type { CascaderProps } from 'element-plus';

const originCodes = ref<string[]>([]);
const regionTree = ref(/* ... */);

const cascaderProps: CascaderProps = {
  value: 'code',
  label: 'name',
  children: 'children',
  emitPath: true,
  checkStrictly: true
};
</script>
```

#### 下拉选择器（多选）

```vue
<template>
  <floating-label
    label="请选择标签"
    type="select"
    v-model="form.tags"
    :multiple="true"
    clearable
  >
    <el-option label="标签1" value="tag1" />
    <el-option label="标签2" value="tag2" />
    <el-option label="标签3" value="tag3" />
  </floating-label>
</template>
```

## 4. API 文档

### 4.1 组件属性（Props）

#### 通用属性

| 属性名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `label` | `string` | - | **必填**，标签文字（初始状态显示） |
| `floatedLabel` | `string` | - | 激活状态的标签文字（可选，不传则自动从 label 提取） |
| `type` | `'input' \| 'date' \| 'select' \| 'cascader'` | `'input'` | 组件类型 |
| `v-model` | `any` | - | 绑定值 |
| `disabled` | `boolean` | `false` | 是否禁用 |
| `clearable` | `boolean` | `true` | 是否可清除 |

> **标签智能简化**：如果不传 `floatedLabel`，组件会自动从 `label` 中去除"请输入"、"请选择"等前缀作为激活状态的标签。

#### 输入框专属属性（type="input"）

| 属性名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `inputType` | `'text' \| 'textarea' \| 'password' \| 'number'` | `'text'` | 输入框类型 |
| `maxlength` | `number` | - | 最大输入长度 |
| `showWordLimit` | `boolean` | `false` | 是否显示字数统计 |

#### 日期选择器专属属性（type="date"）

| 属性名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `dateType` | `'date' \| 'datetime' \| 'datetimerange' \| 'daterange' \| 'month' \| 'monthrange'` | `'date'` | 日期选择器类型 |
| `unlinkPanels` | `boolean` | `false` | 范围选择时是否独立面板 |
| `rangeSeparator` | `string` | `'-'` | 日期范围分隔符 |
| `valueFormat` | `string` | - | 日期格式化 |
| `startPlaceholder` | `string` | - | 范围开始占位符 |
| `endPlaceholder` | `string` | - | 范围结束占位符 |
| `format` | `string` | - | 显示在输入框中的格式（如 `YYYY-MM`） |

#### 级联选择器专属属性（type="cascader"）

| 属性名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `cascaderOptions` | `array` | `[]` | 选项树，对应 `el-cascader` 的 `options` |
| `cascaderOptionProps` | `CascaderProps` | - | 透传给 `el-cascader` 的 `props`（字段映射、`emitPath`、`checkStrictly` 等） |
| `cascaderFilterable` | `boolean` | `true` | 是否可筛选 |

#### 下拉选择器专属属性（type="select"）

| 属性名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `multiple` | `boolean` | `false` | 是否多选 |
| `collapseTags` | `boolean` | `true` | 多选时是否折叠标签 |
| `collapseTagsTooltip` | `boolean` | `true` | 多选折叠时是否显示tooltip |
| `filterable` | `boolean` | `false` | 是否可搜索（本地过滤） |
| `remote` | `boolean` | `false` | 是否远程搜索 |
| `remoteMethod` | `(query: string) => void` | - | 远程搜索方法 |
| `loading` | `boolean` | `false` | 远程搜索加载状态 |
| `teleported` | `boolean` | `true` | 下拉框是否插入body |

**注意**：使用 `type="select"` 时，需要在组件内部使用 `<slot>` 传入 `<el-option>` 选项。

```vue
<floating-label type="select" v-model="value">
  <el-option label="选项1" value="1" />
  <el-option label="选项2" value="2" />
</floating-label>
```

**远程搜索示例**：

```vue
<template>
  <floating-label
    v-model="form.salesperson"
    label="请输入销售人员姓名"
    type="select"
    :filterable="true"
    :remote="true"
    :remote-method="searchSalesperson"
    :loading="loading"
    clearable
  >
    <el-option
      v-for="item in options"
      :key="item.value"
      :label="item.label"
      :value="item.value"
    />
  </floating-label>
</template>

<script setup>
import { ref } from 'vue';

const loading = ref(false);
const options = ref([]);

const searchSalesperson = async (query) => {
  if (!query) {
    options.value = [];
    return;
  }
  
  loading.value = true;
  try {
    const response = await fetchSalespersonAPI(query);
    options.value = response.data;
  } finally {
    loading.value = false;
  }
};
</script>
```

### 4.2 v-model 数据类型

| 组件类型 | 数据类型 | 示例 |
|----------|----------|------|
| `type="input"` | `string` | `"admin"` |
| `type="date"` + `dateType="date"` | `string` | `"2025-12-25"` |
| `type="date"` + `dateType="datetimerange"` | `[string, string]` | `["2025-12-25 00:00:00", "2025-12-25 23:59:59"]` |
| `type="date"` + `dateType="month"` | `string` | `"2025-12"` |
| `type="date"` + `dateType="monthrange"` | `[string, string]` | `["2025-01", "2025-12"]` |
| `type="select"` (单选) | `string \| number` | `0` 或 `"active"` |
| `type="select"` + `multiple` (多选) | `Array<string \| number>` | `[0, 1, 2]` 或 `["tag1", "tag2"]` |
| `type="cascader"` | `array`（路径） | `["110000","110100"]` |

## 6. 集成步骤

### 6.1 替换现有输入框

**步骤 1**：在组件中导入浮动标签组件

```typescript
import FloatingLabel from '@shared/FloatingLabel/index.vue';
```

**步骤 2**：找到需要替换的 `el-input` 组件

```vue
<el-input
  clearable
  v-model.trim="form.fieldName"
  placeholder="请输入xxx"
/>
```

**步骤 3**：替换为 `floating-label` 组件

```vue
<floating-label
  label="请输入xxx"
  type="input"
  v-model.trim="form.fieldName"
  clearable
/>
```

### 6.2 替换下拉选择器

**步骤 1**：找到需要替换的 `el-select` 组件

```vue
<el-select
  v-model="form.status"
  placeholder="请选择状态"
  clearable
  style="width: 100%"
>
  <el-option label="开启" :value="0" />
  <el-option label="关闭" :value="1" />
</el-select>
```

**步骤 2**：替换为 `floating-label` 组件

```vue
<floating-label
  v-model="form.status"
  label="请选择状态"
  type="select"
  clearable
  style="width: 100%"
>
  <el-option label="开启" :value="0" />
  <el-option label="关闭" :value="1" />
</floating-label>
```

**注意事项**：
- 添加 `type="select"` 指定组件类型
- 将 `placeholder` 改为 `label`
- `<el-option>` 选项保持不变，直接放在组件内部
- 保留 `style="width: 100%"`（如果原来有）
- 多选模式添加 `:multiple="true"`

## 7. 样式定制

### 7.1 主题颜色

浮动标签组件使用 Element Plus 的 CSS 变量，自动适配系统主题：

| CSS 变量 | 用途 | 默认值 |
|----------|------|--------|
| `--el-color-primary` | 聚焦时的标签颜色 | 主题色 |
| `--el-text-color-placeholder` | 未激活时的标签颜色 | 灰色 |
| `--el-text-color-regular` | 有值时的标签颜色 | 常规文字色 |
| `--el-text-color-disabled` | 禁用时的标签颜色 | 禁用色 |
| `--el-fill-color-blank` | 标签背景色 | 白色 |

### 7.2 自定义样式（不推荐）

如需特殊定制，可通过全局样式覆盖：

```scss
// 在全局样式文件中
.floating-label-wrapper {
  .floating-label {
    font-weight: 500; // 标签加粗
  }
  
  &.is-focused .floating-label {
    color: #ff6b6b; // 自定义聚焦颜色
  }
}
```

**注意**：不建议频繁定制，保持系统一致性。

## 8. 注意事项

### 8.1 响应式布局

浮动标签组件会自动撑满父容器，在栅格布局中使用时：

```vue
<!-- 正确：自动撑满 -->
<el-col :lg="6" :md="12" :sm="12" :xs="24">
  <floating-label label="用户账号" type="input" v-model="form.username" />
</el-col>

<!-- 错误：不要设置固定宽度 -->
<el-col :lg="6" :md="12" :sm="12" :xs="24">
  <floating-label 
    label="用户账号" 
    type="input" 
    v-model="form.username"
    style="width: 200px"
  />
</el-col>
```

### 8.2 v-model 修饰符

支持所有 Vue 的 v-model 修饰符：

```vue
<!-- 自动去除首尾空格 -->
<floating-label v-model.trim="form.username" />

<!-- 自动转为数字 -->
<floating-label v-model.number="form.age" />

<!-- 懒更新（失焦时更新） -->
<floating-label v-model.lazy="form.description" />
```

### 8.3 禁用状态

```vue
<floating-label
  label="用户账号"
  type="input"
  v-model="form.username"
  :disabled="true"
/>
```

禁用时：
- 标签颜色变为禁用色
- 输入框不可编辑
- 鼠标样式显示为 `not-allowed`

### 8.4 下拉选择器使用注意

使用 `type="select"` 时的特殊说明：

```vue
<!-- 正确：使用 slot 传入选项 -->
<floating-label type="select" v-model="form.status">
  <el-option label="开启" :value="0" />
  <el-option label="关闭" :value="1" />
</floating-label>

<!-- 错误：不能使用 options 属性 -->
<floating-label type="select" v-model="form.status" :options="[...]" />
```

**多选模式**：
- 设置 `:multiple="true"` 开启多选
- v-model 绑定的值必须是数组类型
- 默认会折叠标签，可通过 `:collapse-tags="false"` 禁用

```vue
<floating-label
  type="select"
  :multiple="true"
  v-model="form.tags"
  label="请选择标签"
>
  <el-option label="标签1" value="1" />
  <el-option label="标签2" value="2" />
</floating-label>
```

### 8.5 与表单验证结合

浮动标签组件可以和 Element Plus 的表单验证结合使用：

```vue
<el-form :model="form" :rules="rules" ref="formRef">
  <el-form-item prop="username">
    <floating-label
      label="用户账号"
      type="input"
      v-model="form.username"
    />
  </el-form-item>
</el-form>
```

## 9. 常见问题

### Q1: 标签文字和边框重叠？
**A**: 这是旧版本的 bug，请确保使用最新版本的组件（v1.1+）。最新版本已通过调整 padding 和 z-index 解决此问题。

### Q2: 日期范围选择器的标签位置不对？
**A**: 确保使用了 `:unlink-panels="true"`（带冒号绑定）而不是 `unlink-panels`。

### Q3: 组件宽度不对？
**A**: 检查父容器是否正确设置了宽度。浮动标签组件会自动撑满父容器（width: 100%）。

### Q4: 能否在弹窗中使用？
**A**: 可以。在 Dialog、Drawer 等弹窗组件中正常使用即可，无需特殊处理。

### Q5: 初始有值时标签不在上方？
**A**: 检查 v-model 绑定的值是否为空字符串。组件会自动检测 null、undefined、空字符串和空数组。

### Q6: 动画效果卡顿？
**A**: 确保浏览器硬件加速已开启。组件使用 CSS3 transform 实现动画，性能表现良好。

### Q7: 如何移除清除按钮？
**A**: 设置 `:clearable="false"` 即可移除清除按钮。

```vue
<floating-label
  label="用户账号"
  type="input"
  v-model="form.username"
  :clearable="false"
/>
```

### Q8: 能否支持其他 Element Plus 组件？
**A**: 当前版本支持 `el-input`、`el-date-picker`、`el-select` 以及 **`el-cascader`（`type="cascader"`）**。如需支持其他组件（如 `el-tree-select`），可在此基础上扩展或联系前端团队。

### Q9: 下拉选择器如何使用可搜索功能？
**A**: 

**本地搜索**：设置 `:filterable="true"` 即可开启本地过滤。

```vue
<floating-label
  type="select"
  :filterable="true"
  v-model="form.city"
  label="请选择城市"
>
  <el-option label="北京" value="beijing" />
  <el-option label="上海" value="shanghai" />
  <el-option label="广州" value="guangzhou" />
</floating-label>
```

**远程搜索**：同时设置 `:remote="true"` 和 `:remote-method` 实现远程搜索。

```vue
<template>
  <floating-label
    type="select"
    :filterable="true"
    :remote="true"
    :remote-method="searchRemote"
    :loading="loading"
    v-model="form.value"
    label="请输入关键词搜索"
  >
    <el-option
      v-for="item in options"
      :key="item.value"
      :label="item.label"
      :value="item.value"
    />
  </floating-label>
</template>

<script setup>
const loading = ref(false);
const options = ref([]);

const searchRemote = async (query) => {
  if (!query) return;
  loading.value = true;
  try {
    const res = await fetchAPI(query);
    options.value = res.data;
  } finally {
    loading.value = false;
  }
};
</script>
```

### Q10: 多选时标签太多怎么办？
**A**: 默认会自动折叠标签。可以通过以下属性控制：
- `:collapse-tags="true"` - 是否折叠（默认true）
- `:collapse-tags-tooltip="true"` - 折叠时是否显示tooltip（默认true）

```vue
<floating-label
  type="select"
  :multiple="true"
  :collapse-tags="true"
  :collapse-tags-tooltip="true"
  v-model="form.tags"
>
  <!-- 选项 -->
</floating-label>
```

### Q11: 如何自定义激活状态的标签文案？
**A**: 组件默认会自动去除"请输入"、"请选择"等前缀。如果需要自定义，使用 `floated-label` 属性：

```vue
<!-- 自动简化：请输入事件名称 → 事件名称 -->
<floating-label label="请输入事件名称" />

<!-- 手动指定：请输入事件名称 → 事件 -->
<floating-label label="请输入事件名称" floated-label="事件" />

<!-- 不含前缀时保持不变：用户账号 → 用户账号 -->
<floating-label label="用户账号" />
```

### Q12: 标签自动简化支持哪些前缀？
**A**: 目前支持以下前缀的自动去除：
- `请输入` - 如"请输入用户名" → "用户名"
- `请选择` - 如"请选择状态" → "状态"
- `请填写` - 如"请填写手机号" → "手机号"
- `请选择或输入` - 如"请选择或输入城市" → "城市"

## 10. 最佳实践

### 10.1 统一标签文字格式

建议标签文字遵循以下格式，组件会自动智能简化：

| 场景 | label（初始状态） | 激活状态自动简化为 |
|------|-------------------|-------------------|
| 输入框 | "请输入用户账号" | "用户账号" |
| 选择器 | "请选择状态" | "状态" |
| 日期范围 | "时间范围" | "时间范围"（无前缀不变） |
| 月份选择 | "请选择月份" | "月份" |

**自定义激活标签**：如果自动简化不符合需求，可通过 `floatedLabel` 属性指定：

```vue
<!-- 使用自动简化 -->
<floating-label label="请输入事件名称" />
<!-- 初始: 请输入事件名称 → 激活: 事件名称 -->

<!-- 手动指定激活标签 -->
<floating-label label="请输入事件名称" floated-label="事件" />
<!-- 初始: 请输入事件名称 → 激活: 事件 -->
```

### 10.2 合理使用清除功能

筛选表单中建议始终开启 `clearable`，方便用户快速清空：

```vue
<floating-label clearable />  <!-- 推荐 -->
<floating-label :clearable="false" />  <!-- 不推荐 -->
```

### 10.3 适度使用

浮动标签适合：
- 筛选表单
- 搜索框
- 数据录入表单
- 下拉选择（单选/多选）

不适合：
- 登录表单（传统样式更清晰）
- 紧凑型表格内编辑
- 超短输入框（如验证码）
- 选项特别多的下拉框（建议使用搜索功能）

### 10.4 保持一致性

在同一个页面或模块中，建议要么全部使用浮动标签，要么全部使用传统输入框，避免混用。
