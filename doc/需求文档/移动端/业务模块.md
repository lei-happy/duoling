## 一、功能概述

基于 UniApp 开发微信小程序，包括管理人员端和驾驶员端两个角色视角。

## 二、业务背景

移动端是企业端 Web 系统的延伸，复用后端 Client API。当前无任何代码实现。

## 三、需求详情

### 3.1 技术基础
- UniApp + Vue 3 + TypeScript
- 微信小程序 + H5 双端适配
- 复用后端 JWT 认证体系

### 3.2 管理人员端
- 运单查看与搜索
- 运单审批操作
- 调度操作
- 消息通知

### 3.3 驾驶员端
- 接单/拒单
- 在途状态更新
- 电子回单拍照上传
- 个人运费查询
