## 一、功能概述

实现运单全生命周期管理，包括运单创建、调度、在途跟踪、签收、回单等核心业务流程。

## 二、业务背景

运单管理是物流车队系统的核心业务模块，贯穿从客户下单到结算完成的全流程。ORM 模型 Order 已定义基础字段。

## 三、需求详情

### 3.1 运单管理
- 运单全生命周期：创建 → 调度 → 装车 → 在途 → 签收 → 回单 → 结算
- 运单 CRUD + 批量操作
- 数据导入导出

### 3.2 调度管理
- 调度看板
- 派车/派人操作
- 调度记录

### 3.3 在途追踪
- 状态更新
- 异常事件记录

### 3.4 回单管理
- 电子回单上传
- 回单审核流程

### 3.5 消息通知
- 站内消息
- 业务提醒
