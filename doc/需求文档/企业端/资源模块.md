## 一、功能概述

实现企业端的车辆、驾驶员、客户、路线、网点等资源管理功能。

## 二、业务背景

ORM 模型（Vehicle、Driver、Customer、Route）已定义，需实现完整的 CRUD API 和前端页面。

## 三、需求详情

### 3.1 车辆管理
- CRUD + 状态管理（空闲/在途/维修/报废）
- 车辆档案（证件照片）
- 证件到期提醒

### 3.2 驾驶员管理
- CRUD + 状态管理
- 与车辆绑定
- 驾驶员账号关联

### 3.3 客户管理
- CRUD + 分类（发货方/收货方/三方）
- 合同管理
- 地址簿

### 3.4 路线管理
- CRUD + 路线报价
- 地区库关联

### 3.5 经销商/网点管理
- 企业合作网点维护
