## 一、功能概述

实现企业端的组织架构、角色权限、员工管理、菜单管理、数据字典等基础功能模块。

## 二、业务背景

企业端基础模块前端页面已就绪（基于 EleAdminPlus），后端 Client API 未实现。需补充 ORM 模型（biz_role_menu、biz_user_role、biz_department）并实现完整 CRUD API。

## 三、需求详情

### 3.1 组织架构管理
- 树形部门结构（biz_department）
- 部门 CRUD、拖拽排序
- 部门负责人设置

### 3.2 角色管理
- 角色 CRUD（biz_role）
- 角色菜单分配（biz_role_menu）
- 数据权限范围配置

### 3.3 员工管理
- 员工 CRUD（biz_user）
- 部门/角色关联
- 状态管理（在职/离职/试用）
- 邀请注册

### 3.4 菜单管理
- 菜单 CRUD（biz_menu）
- 受产品版本功能清单控制

### 3.5 数据字典
- 企业级字典管理
- 初始数据从平台同步

### 3.6 企业设置
- 企业基本信息维护
- 业务参数配置
