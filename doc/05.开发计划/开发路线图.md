## 二、核心架构：渐进式表初始化

### 2.1 三层表架构

租户数据库表按需分层创建，避免一次性创建所有表。

| 层级 | 触发时机 | 包含表 |
|------|----------|--------|
| **Tier 1: Core** | 企业注册时 | biz_user、biz_role、biz_menu、biz_department、biz_user_role、biz_role_menu、biz_region、biz_operation_log、biz_dict、biz_dict_item |
| **Tier 2: Business** | 产品版本开通时 | biz_vehicle、biz_driver、biz_customer、biz_route、biz_order（需求明确后设计） |
| **Tier 3: Premium** | 高级版本开通时 | 结算表、BI 统计表等（后续设计） |

### 2.2 产品版本 → 菜单/表控制链路

```
企业登录 → 查 sys_tenant_product（有效版本）
         → 查 sys_version_feature（版本功能清单）
         → 收集 feature_code 列表
         → 过滤 sys_menu（feature_code IN ...）
         → 按角色过滤 → 返回菜单

版本开通 → 查 sys_version_feature → 收集 required_tables
         → ensure_tenant_tables（按需创建业务表）
```

### 2.3 产品版本功能对应

| 版本 | 功能模块 |
|------|----------|
| basic | 工作台、系统管理（组织/员工/角色/字典/日志） |
| standard | + 资源管理（车辆/驾驶员/客户/路线）、业务管理（运单/调度/追踪/回单） |
| pro | + 财务管理（应收/应付/对账）、数据分析（看板/报表） |
| enterprise | 全功能 |

## 三、开发阶段规划

### 阶段一：基础设施重构 + SaaS 核心能力（预计 1~2 周） ✅

#### 1.1 三层表架构实现 ✅

- `TenantModelBase` 增加 `__table_tier__` 属性（core / business / premium）
- `DatabaseManager.create_tenant_database` 仅创建 core 层表
- `DatabaseManager.ensure_tenant_tables` 支持按需创建指定表
- 5 个业务模型（Vehicle/Driver/Order/Route/Customer）标记为 `__table_tier__ = "business"`

#### 1.2 补充基础设施层模型 ✅

新增 6 个 Core 层 ORM 模型：
- `BizDepartment` — 部门/组织架构
- `BizUserRole` — 用户角色关联
- `BizRoleMenu` — 角色菜单关联
- `BizRegion` — 全国行政区划（从平台 sys_regions 同步）
- `BizOperationLog` — 租户级操作日志
- `BizDict` / `BizDictItem` — 租户级数据字典

#### 1.3 种子数据初始化 ✅

`TenantService.create_tenant` 流程增加：
- 默认角色（管理员/操作员/驾驶员）
- 默认部门（总公司 → 运营部/车队部/财务部）
- 管理员用户 + 角色关联
- 地区数据从平台 `sys_regions` 同步

#### 1.4 产品版本功能控制 ✅

- `sys_menu` 新增 `feature_code` 字段
- 新增 `sys_product_feature` + `sys_version_feature` 表
- `ProductFeatureService` — 功能清单 CRUD + 版本关联
- `AuthService._get_user_menus` 加入版本-功能过滤逻辑
- `TenantService.assign_product` 加入动态建表逻辑

#### 1.5 Client 端菜单树 ✅

在 `sys_menu` 定义完整的 Client 菜单树（app_type=client），包含：
- 首页（工作台）
- 系统管理（组织架构/员工/角色/字典/操作记录/登录记录）
- 资源管理（车辆/驾驶员/客户/路线）
- 业务管理（运单/调度/在途追踪/回单）
- 财务管理（应收/应付/对账）
- 数据分析（运营看板/数据报表）
