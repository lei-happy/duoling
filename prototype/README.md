# 产品原型目录

本目录是 Console「文档中心 → 设计对接」的**唯一原型根目录**。

- 只扫描本目录下的多级文件夹与 `.html` / `.htm` 文件
- 每个 HTML 文件即一条可预览的产品原型
- 可按产品端、功能模块自由建多级子目录
- 移动端高保真规范见 [`移动端/DESIGN.md`](移动端/DESIGN.md)（融合 apple-design + frontend-design）

## 推荐结构

```text
prototype/
  运营端/
    系统管理/
      菜单管理.html
  企业端/
    运单/
      运单列表.html
  移动端/
    DESIGN.md                    移动端高保真规范（设计 token / 微信规范 / 动效参数）
    驾驶员微信小程序/            13 个模块 + assets/{mp.css,mp.js}
    后台人员微信小程序/          14 个模块 + assets/{mp.css,mp.js}
```

## 移动端原型

两个微信小程序，共 27 个模块页面。每个 HTML 内含 iPhone 外壳与微信 chrome，左侧是设计说明，顶部「屏幕索引」chip 可直接跳到任意状态屏。纯静态、无外部依赖，可离线打开。

**驾驶员微信小程序**（tabBar：任务 / 收入 / 消息 / 我的）

`01` 登录与身份 · `02` 工作台首页 · `03` 任务列表与筛选 · `04` 任务详情与流转 · `05` 任务执行动作 · `06` 回单上传 · `07` 位置与导航 · `08` 异常上报 · `09` 我的收入 · `10` 资金账户与油卡 · `11` 我的车与证照 · `12` 消息与订阅 · `13` 我的与设置

视觉记忆点是**票据质感的调令卡 + 公路进度线**（装车 → 出发 → 到达 → 签收，路标点随状态弹簧点亮）。正文 16px 起、点击区 ≥ 48px。

**后台人员微信小程序**（tabBar：工作台 / 调度 / 数据 / 消息 / 我的）

`01` 登录与企业切换 · `02` 角色自适应工作台 · `03` 经营驾驶舱 · `04` 计划中心与确认 · `05` 调度工作台五阶段 · `06` 派车与分配承运 · `07` 在途监控与预警 · `08` 回单签收 · `09` 费用工作台 · `10` 审批中心 · `11` 运营看板 · `12` 资源与客商速查 · `13` 消息中心 · `14` 我的与设置

视觉记忆点是**五阶段泳道卡带**（待分配 / 待派车 / 待装车 / 在途 / 待签收，横向滑动切档、超时数呼吸），以及派车页的**毛利即时反馈条**。02 顶部可实时切换老板 / 调度 / 财务三个视图。

两端共用间距、圆角、字阶与状态色，主色按人群分化：驾驶员 `#1D4ED8` + 工程警示黄，后台 `#2F54EB` + 琥珀。动效为自研 spring runtime，全量支持 `prefers-reduced-motion` 与 `prefers-reduced-transparency`。

## 使用方式

1. 在本目录新增/调整 HTML 原型（及同目录 css/js/图片等资源）
2. 打开运营端「文档中心 → 设计对接」
3. 编辑模块时「选择原型」，从目录树点选 HTML，即可内嵌预览

部署时由环境变量 `PROTO_ROOT` 指向该目录（本地默认即为仓库根下 `prototype/`）。
