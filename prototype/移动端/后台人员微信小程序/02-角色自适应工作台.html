Admin Mini Program · 02

角色自适应工作台

同一个入口，三种人看到三件不同的事。老板看水位与放行，调度看任务池与超时，财务看待付与审批。不做一个所有人都用不顺手的通用首页。

设计说明

  • 顶部角色切换器可实时切四个视图（点一下看效果）：调度 / 老板 / 财务 / 车队长。多角色的人不用退出重登。
  • 调度视图的五阶段泳道卡带是后台端的记忆点：待分配 / 待派车 / 待装车 / 在途 / 待签收 横向滑动，选中档位下方列表跟着换，超时数缓慢呼吸。
  • 每个视图只有一个强调色动作：调度是「去派车」，老板是「批」，财务是「标记支付」，车队长是「催司机」。
  • KPI 口径与 PC 驾驶舱一致：计划运费、计划数、商品车数量、服务客户数、毛利率，不在手机上另造一套指标。
  • 财务视图对没有权限的人连数字都不显示，而不是显示后再报错。
