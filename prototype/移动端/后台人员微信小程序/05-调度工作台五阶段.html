Admin Mini Program · 05

调度工作台 · 五阶段

调度的一天就是把任务从左往右推。待分配 → 待派车 → 待装车 → 在途 → 待签收，卡在哪一档一眼看到，手指点一下就切过去。

设计说明

  • 五阶段泳道卡带横向滑动、吸顶常驻。选中档位是深蓝实心 + 琥珀左标，超时数字缓慢呼吸——不用红点轰炸，但绝不让人漏掉。
  • 阶段名与状态机严格对齐：待分配 / 待派车 / 已派车（待装车）/ 在途 / 待签收，不在手机上另起一套叫法。
  • 每档列表的第一行操作不一样：待派车给「派车」，在途给「催位置」，待签收给「催回单」。同一个列表组件，动作跟着阶段变。
  • 批量模式是调度的效率关键：勾选多单一次派给同一辆车 / 同一家承运商。进入批量时左滑操作自动禁用，避免误触。
  • 每档顶部有一句话小结，说清这一档现在最该处理什么，而不是让人自己数。
  • 下拉刷新用橡皮筋阻尼；切档列表做 6px 上浮淡入，让"换了一批数据"这件事被看见。
