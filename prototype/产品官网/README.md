# 产品官网原型

**朵灵·企云**（北京朵灵科技有限公司）面向**轿运行业（汽车物流）**的企业综合操作系统官网设计稿。司机端产品为 **朵灵·司机**。

核心转化路径：**看懂数智化四层能力 → 测出自己的水位 → 知道该买哪个版本**。

在 Console「文档中心 → 设计对接」中可逐页内嵌预览；本地直接双击 HTML 也能打开（无外部 CDN 依赖）。

## 设计口径

**视觉**：主色深墨青 `#0F4C5C`、强调色暖橙 `#C45C26`，与销售物料《企业数智化转型-管理者精读版》同源，避免官网与销售材料两套观感。深色区块与浅色区块交替形成节奏。

**记忆点**：贯穿三个页面的「水位刻度尺」（L1–L8 八格 + 橙色指针）。它来自"先量水位再建设"这个业务概念，在首页是钩子、在自测页是交互主体、在转型页以四列阶段卡与 Banner 幻灯呼应。

**产品矩阵**：朵灵·企云（租户端）+ 朵灵·司机。承运商协同是企云能力，不作为独立产品对外卖。

**定价口径**：基础版 / 旗舰版只按功能深度区分，不限账号与车辆数；付费周期仅月付 / 年付。实施以企业线上自助为主，不写驻场顾问陪跑。

**版本能力口径（与 `version_feature.json` 对齐）**：

- **基础版（standard）**：能源中心仅账户侧（供应商站点、账户、卡、充值、设置）；财务仅应付路径（任务费用、承运商对账结算、司机工资单）
- **旗舰版（pro）**：能源消费 / 接入 / 对账 / 风控 / 分析全开；财务补齐应收、出纳、进销项发票、经营核算与对账工作台

**开放平台 / MCP 的口径**：这是"你自己的 AI 也能用我们的数据"，与内置 AI 数字员工是两件事，所以在首页单独成块（配真实的 `mcpServers` 配置结构），在产品能力页作为「主线 04 / 对外连接」展开。文案严格贴合已实现范围：

- 只写"复制配置即可连接"、"按连接勾选授权"、"敏感字段脱敏"、"调用留痕与限流"，均已实现
- 当前 MCP 侧只开放 4 项只读能力（连接自检、查客户、查车辆、查运单），页面明确写了"写入类能力在规划中"，不宣称 AI 能直接建单改单
- 不提 OAuth、stdio 本地部署、Token 一键轮换、多 AI 工具专属向导（均未实现）
- `open_platform` 在 lite / 运力宝 / 标准版 / 专业版**全部包含**，所以对比表标注"全版本可用"，没有当成旗舰版卖点
- 价格页新增一条 FAQ 说明：走 MCP 用自己的 AI 不消耗 AI 用量包额度

**自测计分**：与精读版完整 20 题保持同一套判定逻辑，便于两边结论一致。

- 开头 3 道不计分画像题（板车规模、现有管法、最想先解决的一块）
- 10 题分布：业务在线 3 题、数据贯通 3 题、智能应用 2 题、经营闭环 2 题
- 各维折算到 20 分制（前两维 ×5/3，后两维 ×2.5），总分 0–80
- 先按总分落档，再按短板维度封顶；L8 额外要求四维均 ≥14
- 未答完不出档位，只提示剩余题数并高亮未答题

## 与线上官网的关系

现有 Vue 官网在 `frontend/website`（首页 / 产品功能 / 价格方案 / 注册 / 关于 / 更新记录）。本目录只是设计原型，未改动线上代码。原型确认后落地时需注意：

- 现有 `Pricing.vue` 写的是「标准版 ¥4999 / 高级版 ¥9999」，与后台配置和本原型都不一致，落地时统一口径
- 自测页的留资表单需要接后端线索接口，当前仅做前端占位提示
- 「完整转型报告」下载与 20 题深度自检页尚未设计，当前指向留资
