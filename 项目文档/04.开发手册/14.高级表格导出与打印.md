# 高级表格（ele-pro-table）导出与打印

> 适用于 `frontend/client`、`frontend/console`、`frontend/template` 中基于 **EleAdmin Plus** 的 `ele-pro-table` 页面。

---

## 1. 全局策略说明

项目在 `src/config/use-global-config.ts` 中通过 **`tableConfig.tools`** 控制表格右上角默认工具栏。

- **默认（全局）**：不包含「导出」「打印」按钮，仅保留刷新、密度、列设置、全屏等常用项。
- **原因**：多数业务列表不需要导出/打印；需要时在单页显式开启，避免误操作与界面干扰。

默认工具栏与预设常量定义在 **`src/config/pro-table-tool-presets.ts`**（三端各有一份，路径相同）：

| 常量 | 说明 |
|------|------|
| `proTableToolsDefault` | 与全局 `tableConfig.tools` 一致，无导出、无打印 |
| `proTableToolsWithExport` | 在默认基础上增加 **导出** |
| `proTableToolsWithExportPrint` | 在默认基础上增加 **导出** 与 **打印** |

---

## 2. 单页开启导出 / 打印

### 2.1 仅需要右上角「导出」

1. 在 `<script setup>` 中引入：

```typescript
import { proTableToolsWithExport } from '@/config/pro-table-tool-presets';
```

2. 在 `ele-pro-table` 上同时配置 **`tools`** 与 **`export-config`**（导出逻辑依赖 `export-config`）：

```vue
<ele-pro-table
  :tools="proTableToolsWithExport"
  :export-config="{ fileName: '某某数据', datasource: exportSource }"
  ...
/>
```

- `fileName`：导出默认文件名（可按业务修改）。
- `datasource`：可选；与列表分页数据源类似，用于「导出全部/按条件导出」时拉全量或筛选数据。若仅需导出当前页数据，可参考现有示例页面写法。

### 2.2 需要「导出」+「打印」

1. 引入：

```typescript
import { proTableToolsWithExportPrint } from '@/config/pro-table-tool-presets';
```

2. 在表格上配置：

```vue
<ele-pro-table
  :tools="proTableToolsWithExportPrint"
  :export-config="{ fileName: '某某数据', datasource: exportSource }"
  :print-config="{ datasource: exportSource }"
  ...
/>
```

- `print-config` 与 `export-config` 类似，可按需传入 `datasource`、`columns`、`modalProps` 等（详见 EleAdmin Plus 文档与项目内已有示例）。

### 2.3 仅代码触发导出，不要右上角图标

若页面只在工具栏自定义按钮里调用 `tableRef.exportData()`，且不需要右上角导出图标，则**不必**设置 `:tools` 中的 `export`；保留全局默认 `tools` 即可，并照常配置 `export-config` 供组件内部使用。

---

## 3. 自定义工具栏顺序（进阶）

若除预设外还需调整顺序或增减项，可自行组装 `TableTool[]`（类型来自 `ele-admin-plus/es/ele-pro-table/types` 的 `TableTool`），例如：

```typescript
import type { TableTool } from 'ele-admin-plus/es/ele-pro-table/types';

const myTools: TableTool[] = [
  'reload',
  'export',
  'size',
  'columns',
  'maximized'
];
```

再在模板中 `:tools="myTools"` 即可。

---

## 4. 相关文件位置（便于检索）

| 说明 | 路径（相对各子应用 `src/`） |
|------|------------------------------|
| 全局表格默认 tools | `config/use-global-config.ts` |
| 预设常量 | `config/pro-table-tool-presets.ts` |
| 全局 Excel 导出插件（已配置） | `use-global-config` 中的 `exportConfig.exportPlugin`（exceljs） |

三端 **`client` / `console` / `template`** 均维护同名文件；改默认行为时建议三端同步，避免各端表现不一致。
