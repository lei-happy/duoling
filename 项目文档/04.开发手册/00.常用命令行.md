# 常用命令行

以下命令需在对应项目根目录执行：`seed_*` 脚本在 **`backend`** 目录下运行。

## 数据种子（Seed）

**产品功能清单**（已存在则跳过，只插入新增）：

```bash
python scripts/seed/seed_product_features.py
```

**客户端菜单**（菜单定义来自 `scripts/seed/sys_menu.json`，默认按匹配键 upsert）：

```bash
python scripts/seed/seed_client_menus.py
```

**客户端菜单（仅补全缺失）**：已存在的菜单不更新，只插入库中尚没有的项。

```bash
python scripts/seed/seed_client_menus.py --insert-only
```



## 后端

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## 前端

```bash
npm run dev
```
