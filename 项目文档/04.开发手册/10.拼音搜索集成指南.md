# 拼音搜索集成指南

## 1. 概述

系统集成了 `pypinyin` 库，用于在下拉选择器、筛选搜索等场景中支持**拼音搜索**和**首字母搜索**，提升中文输入场景下的用户体验。

典型使用场景：
- 客户选择器输入 `bj` 或 `beijing` 可匹配「北京汽车」
- 品牌下拉输入 `dffc` 可匹配「东风风行」
- 地区搜索输入 `sh` 可匹配「上海」

## 3. 核心 API

```python
from pypinyin import lazy_pinyin, Style
```

### 3.1 常用转换方式

```python
name = "东风风行"

# 全拼（小写，无声调）
lazy_pinyin(name)
# => ['dong', 'feng', 'feng', 'xing']

# 首字母
lazy_pinyin(name, style=Style.FIRST_LETTER)
# => ['d', 'f', 'f', 'x']

# 拼接为字符串
"".join(lazy_pinyin(name))                          # => 'dongfengfengxing'
"".join(lazy_pinyin(name, style=Style.FIRST_LETTER)) # => 'dffx'
```

### 3.2 混合文本（中英文数字）

`pypinyin` 只转换汉字部分，非汉字字符原样保留：

```python
lazy_pinyin("A3 长安")
# => ['A', '3', ' ', 'chang', 'an']
```

## 4. 后端集成方案

### 4.1 内存匹配（推荐用于下拉选择器）

适用于数据量较小（< 1000 条）的选择器场景，先查数据库再在 Python 层面做拼音过滤。

**工具函数**（建议放在 `app/common/pinyin_utils.py`）：

```python
"""拼音搜索辅助工具"""

from pypinyin import lazy_pinyin, Style


def match_pinyin(text: str, keyword: str) -> bool:
    """
    判断 text 是否匹配 keyword（支持中文、全拼、首字母）

    匹配规则（均忽略大小写）：
      1. 中文包含匹配：text 包含 keyword
      2. 全拼前缀匹配：'dongfeng' 匹配 'dong'
      3. 首字母前缀匹配：'dffx' 匹配 'df'
    """
    if not keyword:
        return True
    if not text:
        return False

    kw = keyword.lower().strip()
    txt = text.lower()

    # 中文直接包含
    if kw in txt:
        return True

    # 全拼匹配
    full_pinyin = "".join(lazy_pinyin(text)).lower()
    if kw in full_pinyin:
        return True

    # 首字母匹配
    initials = "".join(lazy_pinyin(text, style=Style.FIRST_LETTER)).lower()
    if kw in initials:
        return True

    return False
```

**在 Service 中使用**：

```python
from app.common.pinyin_utils import match_pinyin

class CustomerService:

    @staticmethod
    async def select_customers(
        db: AsyncSession, keyword: Optional[str] = None
    ) -> list:
        result = await db.execute(
            select(Customer).where(Customer.is_deleted == 0, Customer.status == 1)
        )
        items = result.scalars().all()

        if keyword:
            items = [c for c in items if match_pinyin(c.customer_name, keyword)]

        return [
            {"id": c.id, "customerName": c.customer_name}
            for c in items
        ]
```

### 4.2 数据库字段冗余（适用于大数据量分页搜索）

如果数据量较大（> 1000 条），建议在表中增加拼音冗余字段，写入时自动生成：

```python
# 模型增加字段
name_pinyin: Mapped[Optional[str]] = mapped_column(
    String(500), nullable=True, comment="名称全拼"
)
name_initial: Mapped[Optional[str]] = mapped_column(
    String(100), nullable=True, comment="名称首字母"
)
```

```python
# 创建/更新时自动填充
from app.common.pinyin_utils import to_pinyin, to_initial

customer.name_pinyin = to_pinyin(customer.customer_name)
customer.name_initial = to_initial(customer.customer_name)
```

对应的辅助函数：

```python
def to_pinyin(text: str) -> str:
    """转换为全拼字符串"""
    if not text:
        return ""
    return "".join(lazy_pinyin(text)).lower()


def to_initial(text: str) -> str:
    """转换为首字母字符串"""
    if not text:
        return ""
    return "".join(lazy_pinyin(text, style=Style.FIRST_LETTER)).lower()
```

数据库查询时直接用 SQL LIKE：

```python
if keyword:
    kw = f"%{keyword.lower()}%"
    base = base.where(
        or_(
            Customer.customer_name.contains(keyword),
            Customer.name_pinyin.like(kw),
            Customer.name_initial.like(kw),
        )
    )
```

## 5. 前端集成方案

对于纯前端的筛选场景（如 `el-select` 的 `filterable`），可以自定义 `filter-method` 实现拼音过滤。

推荐使用前端拼音库 `pinyin-pro`：

```bash
pnpm add pinyin-pro -w
```

```typescript
import { pinyin, match } from 'pinyin-pro';

// 判断是否匹配
function pinyinMatch(text: string, keyword: string): boolean {
  if (!keyword) return true;
  const kw = keyword.toLowerCase();
  // 中文包含
  if (text.toLowerCase().includes(kw)) return true;
  // 拼音匹配（pinyin-pro 内置）
  return match(text, kw) !== null;
}
```

在 `el-select` 中使用：

```vue
<el-select
  v-model="value"
  filterable
  :filter-method="filterMethod"
>
  <el-option
    v-for="item in filteredOptions"
    :key="item.id"
    :label="item.name"
    :value="item.id"
  />
</el-select>
```

```typescript
const allOptions = ref([]);
const filteredOptions = ref([]);

const filterMethod = (query: string) => {
  if (!query) {
    filteredOptions.value = allOptions.value;
  } else {
    filteredOptions.value = allOptions.value.filter((item) =>
      pinyinMatch(item.name, query)
    );
  }
};
```

## 6. 方案选型建议

| 场景 | 数据量 | 推荐方案 | 说明 |
|------|--------|----------|------|
| 下拉选择器 | < 500 条 | 前端 `pinyin-pro` | 无需后端改动，体验最好 |
| 下拉选择器（远程搜索） | 500~1000 条 | 后端内存匹配 | `match_pinyin` 过滤 |
| 分页列表搜索 | > 1000 条 | 数据库字段冗余 | 新增 `name_pinyin` + `name_initial` 字段 |

---

## 7. 注意事项

1. **多音字**：`pypinyin` 默认根据词组上下文智能选择读音（如「重庆」→ `chongqing`），大多数场景无需特殊处理
2. **性能**：`lazy_pinyin` 的转换开销极小（微秒级），内存匹配 1000 条数据耗时 < 10ms
3. **缓存**：对于频繁调用的选择器接口，可配合 Redis 缓存转换结果
4. **一致性**：如果采用数据库冗余方案，需要在创建和更新时同步维护拼音字段
