# 产品官网内容升级

> **所属阶段**：官网优化迭代
>
> **文档状态**：已确认
>
> **优先级**：高
>
> **涉及页面**：首页（Home）、价格方案（Pricing）、全局导航与页脚

## 一、升级目标

将产品官网的核心定位从"卖系统 / AI操作系统"转向**"帮企业建立利润确定性"**，让访客（尤其是企业决策者）在 30 秒内理解：智途不是一套管理软件，而是让每一台车、每一公里的利润都看得清楚的经营工具。

## 二、业务背景

当前官网存在以下问题：

| 问题 | 表现 |
|------|------|
| 定位偏差 | 主打"AI操作系统""数字化转型"，给人卖系统的印象 |
| 价值模糊 | 强调功能模块（VIN管理、GPS追踪、运力管理），未突出客户核心诉求——利润 |
| 缺乏共鸣 | 没有痛点区，无法打动企业老板 / 决策者 |
| 无社会证明 | 缺少案例数据佐证，说服力不足 |
| 定价混乱 | 三档定价含免费版，FAQ 中版本命名不一致（出现"Pro 版"） |

## 三、首页内容升级

首页由 6 个区块组成，自上而下依次为：Hero → 痛点共鸣 → 解决方案 → 产品能力 → 案例 → 底部 CTA。

UI 视觉风格保持不变（渐变背景、卡片样式、滚动动画）。

### 3.2 痛点共鸣区（新增）

**目的**：打动企业决策者，让他们感到"这说的就是我"。

**区块标题**：这些问题，是不是你每天都在面对？

**采用提问式卡片**，每个问题配一个简短说明：

| 序号 | 问题 | 说明 |
|------|------|------|
| 1 | 为什么你每个月有营收，却不知道赚没赚钱？ | 收入不等于利润，油费、路桥、人工、维修……算不清就看不清。 |
| 2 | 哪些线路在亏钱，你能看清吗？ | 有些线路看着忙，实际每趟都在亏，却一直在跑。 |
| 3 | 哪些客户报价过低，你能识别吗？ | 老客户的报价可能早已低于成本，但你不敢动、也没依据。 |
| 4 | 哪些环节可以提效，你能抓住吗？ | 空驶、等待、绕路……每一个低效环节都在吃利润。 |
| 5 | 为什么规模越大，反而利润越不稳定？ | 车多了、线路多了、客户多了，管理复杂度指数级增长。 |

**交互**：卡片滚动渐入动画，保持现有 `useScrollAnimation` 风格。

---

### 3.3 解决方案区（替代原"核心功能"区块）

**目的**：告诉访客"我们能帮你做什么"，不罗列功能，聚焦结果。

**区块标题**：智途帮你做到的四件事

**区块副标题**：不是给你一套系统，而是帮你建立利润确定性

| 序号 | 方案 | 描述 |
|------|------|------|
| 1 | 看清单车利润 | 每一单运输赚了多少钱，收入、成本、利润自动核算，一目了然。 |
| 2 | 找出亏损线路 | 哪条线路赚钱、哪条亏钱，跑得多不等于赚得多，用数据说话。 |
| 3 | 提供决策依据 | 不再拍脑袋做决定，经营数据实时呈现，每一步都有据可依。 |
| 4 | 优化客户报价 | 识别哪些客户报价偏低、哪些还有空间，让每一单报价都合理。 |

**展示形式**：保留现有 4 张卡片布局，每张卡片包含图标（内联 SVG）+ 标题 + 描述。图标风格从"系统功能"图标替换为"商业结果"图标（如利润趋势、路线地图、数据仪表盘、报价标签等）。

---

### 3.4 产品能力区（替代原"数据统计 + 为什么选择智途"区块）

**目的**：展示产品具体能做到的事，但用"结果"而非"功能"的语言来表达，弱化系统感。

**区块标题**：用结果说话

**区块副标题**：不讲功能模块，只看实际产出

| 能力 | 描述 |
|------|------|
| 单车利润自动核算 | 每台车、每趟运输的收入与成本自动归集，利润实时可见。 |
| 线路盈利能力排名 | 所有运营线路按利润率排序，亏损线路一眼定位。 |
| 客户利润分析 | 按客户维度统计利润贡献，识别低价客户与高价值客户。 |
| 成本结构拆解 | 油费、路桥费、司机工资……每一项成本自动归类，清晰透明。 |

**展示形式**：横向排列的 4 个结果卡片，每个卡片包含标题 + 描述，风格与解决方案区区分（可用不同背景色或图标形式）。

---

### 3.5 案例区（新增）

**目的**：用真实（或模拟）数据增强说服力。

**区块标题**：他们已经看清了利润

**案例内容**（模拟数据，后续可替换为真实案例）：

> **某轿运车队** · 30 台板车 · 华东区域
>
> 使用智途 3 个月后：
> - 发现 **30%** 的线路处于亏损状态
> - 识别出 **5 个** 报价偏低的长期客户
> - 调整报价策略后，整体利润提升 **12%**

**展示形式**：单个大卡片居中展示，左侧案例文字描述，右侧为 3 个核心数据的高亮展示（大数字 + 标签），如：

```
30%         5个          12%
亏损线路发现   低价客户识别    利润提升
```
