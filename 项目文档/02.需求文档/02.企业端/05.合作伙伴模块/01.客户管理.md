# 企业端合作伙伴模块 - 客户管理

> **所属阶段**：阶段四 - 企业端资源模块（合作伙伴子模块）
>
> **文档状态**：已完成
>
> **优先级**：高（运单模块前置依赖）

## 一、功能概述

客户管理是「合作伙伴」模块的第一个子模块。在商品车运输业务中，「客户」是指给物流公司下达运输计划（运单/计划）的上游企业，如主机厂、贸易商、经销商等。客户信息是运单录入和收入计算的基础数据来源。

核心设计原则：

- **合作伙伴体系**：客户管理隶属于合作伙伴模块（`partner/`），后续该模块会扩展承运商、供应商等子模块，保持统一的目录结构和设计范式
- **与计费引擎解耦**：客户表通过 `customer_id` 被运价合同和运单引用，但客户模块本身不直接依赖计费引擎
- **冗余字段策略**：运单和合同中冗余存储 `customer_name`，避免频繁跨表查询

## 二、业务背景

### 核心业务诉求

1. **运单前置依赖**：录入运单时需选择客户（谁给的计划），客户信息是运单的核心要素之一
2. **计费引擎关联**：运价合同绑定到具体客户，通过客户+出发地+目的地匹配运费
3. **财务结算基础**：应收账款按客户维度汇总，需要客户的结算方式、信用代码等信息

## 三、需求详情

### 3.1 客户列表

- 分页表格展示，支持排序
- 列表字段：客户编码、客户名称、客户简称、客户类型、联系人、联系电话、结算方式、状态、操作
- 支持按客户名称/编码/联系人关键字模糊搜索
- 支持按客户类型、结算方式、状态筛选
- 工具栏：新增客户、批量删除
- 行操作：编辑、删除

### 3.2 新增/编辑客户

| 字段 | 说明 | 规则 |
|------|------|------|
| 客户编码 | 系统自动生成或手动输入 | 选填，租户内唯一，格式如 `KH0001` |
| 客户名称 | 客户全称 | 必填 |
| 客户简称 | 便于日常使用的简称 | 选填 |
| 客户类型 | 主机厂/贸易商/经销商/个人/其他 | 必填，下拉选择 |
| 联系人 | 主要联系人姓名 | 选填 |
| 联系电话 | 联系人电话 | 选填，手机号格式校验 |
| 地址 | 客户地址 | 选填 |
| 结算方式 | 月结/票结/预付 | 选填，下拉选择 |
| 统一社会信用代码 | 企业信用代码 | 选填 |
| 备注 | 补充说明 | 选填，文本域 |

### 3.3 删除客户

- 软删除（`is_deleted = 1`）
- 删除前校验：如客户已关联有效运价合同或未完成的运单，禁止删除并提示
- 已停用的客户不影响历史运单的查询和展示

### 3.4 客户状态

| 状态值 | 状态名称 | 说明 |
|--------|---------|------|
| 1 | 正常 | 可在运单中引用 |
| 0 | 停用 | 不可在新运单中引用，历史数据保留 |

### 3.5 客户选择器组件

提供一个可复用的客户选择器组件，供运单录入等场景使用：
- 支持关键字搜索（名称/编码/简称）
- 只展示状态为「正常」的客户
- 选中后回填客户 ID 和客户名称

## 五、API 接口设计

所有接口前缀：`/api/client`，需要 JWT 认证。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/partner/customer` | 分页查询客户 |
| GET | `/partner/customer/{id}` | 查询客户详情 |
| GET | `/partner/customer/select` | 客户选择器（供运单引用，只返回正常状态的客户简要信息） |
| POST | `/partner/customer` | 创建客户 |
| PUT | `/partner/customer/{id}` | 更新客户 |
| DELETE | `/partner/customer/{id}` | 软删除客户 |

**分页查询参数**：

| 参数 | 类型 | 说明 |
|------|------|------|
| page | int | 页码，默认 1 |
| limit | int | 每页条数，默认 20 |
| keyword | string | 名称/编码/联系人模糊搜索 |
| customerType | int | 客户类型筛选 |
| settlementType | int | 结算方式筛选 |
| status | int | 状态筛选 |

**创建/更新请求体**：

```json
{
  "customerCode": "KH0001",
  "customerName": "一汽大众",
  "shortName": "一汽大众",
  "customerType": 0,
  "contactPerson": "张三",
  "contactPhone": "13800138000",
  "address": "吉林省长春市",
  "settlementType": 0,
  "creditCode": "91220101XXXXXXXXXX",
  "remark": ""
}
```

**客户选择器响应**（`GET /partner/customer/select`）：

```json
{
  "code": 0,
  "data": [
    { "id": 1, "customerName": "一汽大众", "shortName": "一汽大众", "customerCode": "KH0001" },
    { "id": 2, "customerName": "上汽通用", "shortName": "上汽通用", "customerCode": "KH0002" }
  ]
}
```
