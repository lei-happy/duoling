# 产品管理

> **所属阶段**：阶段二 - 运营后台完善
>
> **文档状态**：已完成
>
> **优先级**：高

## 一、功能概述

产品管理是运营后台的核心模块，实现「功能模块定义 → 版本配置功能 → 租户开通版本」的完整产品交付链路。通过该模块，运营人员可以灵活管理产品能力、组合版本方案、为租户按需授权，实现不同版本看到不同菜单和功能的精细化控制。

## 二、业务背景

系统采用 SaaS 多租户架构，不同企业（租户）根据购买的产品版本获得不同的功能权限。核心诉求包括：

- 产品功能需要独立管理，支持后期灵活增减模块
- 不同版本包含不同的功能组合，需要灵活配置
- 租户开通版本后，登录客户端只能看到对应版本包含的菜单
- 开通版本时自动在租户库创建功能所需的数据表

### 整体业务流程

```
1. 功能模块管理        2. 产品版本管理         3. 客户管理
   新增/编辑功能   →     配置版本包含的功能  →    为租户开通版本授权
   (sys_product_feature)  (sys_version_feature)    (sys_tenant_product)
                                                         ↓
                                                   4. 租户登录客户端
                                                      按版本过滤菜单显示
                                                      (sys_menu.feature_code)
```

## 三、需求详情

### 3.1 功能模块管理

管理系统的所有产品功能项（`sys_product_feature`），每个功能代表一个可独立授权的业务能力。

#### 3.1.1 功能列表

- 展示所有功能模块，支持按「所属模块」和「状态」筛选
- 列表字段：功能编码、功能名称、所属模块、描述、关联数据表、排序号、状态、创建时间
- 支持新增、编辑、删除操作
- 支持批量选择删除

#### 3.1.2 新增/编辑功能

| 字段 | 说明 | 规则 |
|------|------|------|
| 功能编码 | 唯一标识，对应菜单的 `feature_code` | 必填，格式如 `resource_vehicle`，编辑时不可修改 |
| 功能名称 | 功能的显示名称 | 必填 |
| 所属模块 | 功能归属的业务模块分类 | 从数据字典 `product_module` 加载选项，支持自定义输入 |
| 功能描述 | 功能的详细说明 | 选填 |
| 关联数据表 | 该功能需要的租户库表名列表 | 选填，JSON 数组格式，如 `["biz_vehicle"]` |
| 排序号 | 控制显示顺序 | 默认 0 |
| 状态 | 正常 / 停用 | 仅编辑时可修改，默认正常 |

#### 3.1.3 所属模块数据字典

模块选项通过数据字典 `product_module` 管理，运营人员可在「系统管理 > 数据字典」中维护：

| 字典项值 | 字典项名称 | 说明 |
|----------|-----------|------|
| base | 基础模块 | 所有版本可用的基础功能 |
| resource | 资源管理 | 车辆、驾驶员等资源管理功能 |
| biz | 业务模块 | 运单、调度等业务运营功能 |
| finance | 财务模块 | 应收应付、结算等财务功能 |
| bi | 数据分析 | 报表、看板等数据分析功能 |

后期新增模块时，只需在数据字典中添加新项即可，无需修改代码。

#### 3.1.4 feature_code 命名规范

```
{模块前缀}_{功能名}
```

- `base_dashboard`、`base_system` — 基础模块
- `resource_vehicle`、`resource_driver` — 资源管理
- `biz_order`、`biz_dispatch` — 业务模块
- `finance_receivable` — 财务模块
- `bi_overview`、`bi_report` — 数据分析

目录级菜单通常使用 `xxx_manage`（如 `resource_manage`），子菜单使用具体功能名。

### 3.2 产品版本管理

管理产品的各版本方案（`sys_product_version`），每个版本代表一个可售卖的产品套餐。

#### 3.2.1 版本列表

- 展示所有产品版本
- 列表字段：版本编码、版本名称、描述、最大用户数、最大车辆数、价格、排序号、状态、创建时间
- 支持新增、编辑、删除、配置功能操作

#### 3.2.2 新增/编辑版本

| 字段 | 说明 | 规则 |
|------|------|------|
| 版本编码 | 唯一标识 | 必填，如 `basic`、`standard`、`pro`、`enterprise` |
| 版本名称 | 版本的显示名称 | 必填，如「基础版」「标准版」「专业版」「企业版」 |
| 描述 | 版本的详细说明 | 选填 |
| 最大用户数 | 该版本允许的最大用户数量 | 数字，0 表示不限 |
| 最大车辆数 | 该版本允许的最大车辆数量 | 数字，0 表示不限 |
| 价格 | 版本定价说明 | 文本，如「免费」「2999/年」「面议」 |
| 排序号 | 控制显示顺序 | 默认 0 |
| 状态 | 正常 / 停用 | 仅编辑时可修改 |

#### 3.2.3 配置功能

为版本分配包含的功能模块（`sys_version_feature`）：

- 打开配置弹窗，展示所有可用功能，按「所属模块」分组显示
- 勾选该版本需要包含的功能项
- 保存时全量替换版本与功能的关联关系
- 版本包含的功能决定了租户登录后可见的菜单范围

#### 3.2.4 预置版本方案

| 版本 | 编码 | 功能范围 | 价格 |
|------|------|---------|------|
| 基础版 | basic | 基础模块 | 免费 |
| 标准版 | standard | 基础 + 资源 + 业务 | 2999/年 |
| 专业版 | pro | 标准版 + 财务 + 数据分析 | 9999/年 |
| 企业版 | enterprise | 全部功能 | 面议 |

### 3.3 租户版本授权管理

管理租户与产品版本的授权关系（`sys_tenant_product`），即为租户开通或取消产品版本。

#### 3.3.1 授权入口

在「客户运营中心」的各生命周期视图中，通过客户列表行操作中的「授权管理」按钮进入。

#### 3.3.2 授权管理弹窗

- **已授权列表**：展示该租户当前已开通的所有产品版本，包含版本编码、授权开始时间、授权到期时间，支持取消授权
- **开通新授权表单**：选择产品版本、设置授权开始/到期时间，点击「开通授权」

#### 3.3.3 授权生效机制

开通版本授权后：

1. 系统在 `sys_tenant_product` 表中创建授权记录
2. 根据版本关联的功能模块，获取 `required_tables` 列表
3. 自动在租户独立数据库中创建这些表（若不存在）
4. 租户登录客户端时，系统查询有效授权的版本 → 汇总 `feature_code` 集合 → 过滤菜单

#### 3.3.4 授权到期处理

- 系统定期检查授权到期情况
- 到期后授权状态自动变为已过期
- 租户登录时不再展示过期版本对应的菜单

## 四、数据模型设计

### 4.1 核心数据表

#### sys_product_feature（产品功能清单）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 自增主键 |
| feature_code | VARCHAR(50) UK | 功能编码，唯一 |
| feature_name | VARCHAR(100) | 功能名称 |
| module | VARCHAR(50) | 所属模块（base/resource/biz/finance/bi） |
| description | VARCHAR(255) | 功能描述 |
| required_tables | JSON | 该功能需要的租户库表名列表 |
| sort_order | SMALLINT | 排序号 |
| status | SMALLINT | 状态 0-停用 1-正常 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |
| is_deleted | SMALLINT | 软删除标识 |

#### sys_product_version（产品版本）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 自增主键 |
| version_code | VARCHAR(50) UK | 版本编码，唯一 |
| version_name | VARCHAR(100) | 版本名称 |
| description | VARCHAR(255) | 版本描述 |
| features | JSON | 版本功能概要（冗余，便于展示） |
| max_users | INT | 最大用户数 |
| max_vehicles | INT | 最大车辆数 |
| price | VARCHAR(50) | 价格说明 |
| sort_order | SMALLINT | 排序号 |
| status | SMALLINT | 状态 0-停用 1-正常 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |
| is_deleted | SMALLINT | 软删除标识 |

#### sys_version_feature（版本-功能关联）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 自增主键 |
| version_id | BIGINT | 产品版本 ID |
| feature_id | BIGINT | 功能 ID |
| status | SMALLINT | 状态 0-停用 1-启用 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |
| is_deleted | SMALLINT | 软删除标识 |

#### sys_tenant_product（租户-产品授权）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 自增主键 |
| tenant_id | BIGINT | 租户 ID |
| tenant_code | VARCHAR(50) | 租户编码 |
| version_id | BIGINT | 产品版本 ID |
| version_code | VARCHAR(50) | 版本编码 |
| start_time | DATETIME | 授权开始时间 |
| end_time | DATETIME | 授权到期时间 |
| status | SMALLINT | 状态 0-停用 1-有效 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |
| is_deleted | SMALLINT | 软删除标识 |

#### sys_menu（菜单，与功能的关联字段）

| 字段 | 说明 |
|------|------|
| feature_code | 关联功能编码，为 NULL 表示所有版本可见 |
| app_type | `platform` 为运营后台菜单，`client` 为客户端菜单 |

### 4.2 表关系

```
sys_product_version (1) ──< sys_version_feature >── (N) sys_product_feature
         │                                                    │
         │ version_id                                  feature_code
         │                                                    │
sys_tenant_product                                     sys_menu
(租户 × 版本授权)                              (菜单可见性控制)
```

- **版本 ↔ 功能**：多对多，通过 `sys_version_feature` 关联
- **租户 ↔ 版本**：一对多，一个租户可开通多个版本
- **菜单 ↔ 功能**：通过 `feature_code` 字段语义关联（非外键）

## 七、测试要点

1. **功能模块 CRUD**：新增功能编码唯一性校验、编辑时编码不可修改、删除后不影响已有版本关联
2. **版本功能配置**：全量替换验证、配置保存后重新打开能正确回显已选功能
3. **租户授权**：开通授权后验证 `sys_tenant_product` 记录正确、租户库表自动创建
4. **菜单可见性**：不同版本的租户登录后，只能看到对应 `feature_code` 的菜单，`feature_code` 为空的菜单所有版本可见
5. **授权到期**：到期后租户登录验证菜单是否正确隐藏
6. **数据字典联动**：在数据字典中新增模块选项后，功能模块管理的「所属模块」下拉应能实时显示新选项
