# 本地开发环境 · 常用命令

> 以下命令默认在 **PowerShell** 中执行。路径以项目根目录 `d:\zhitu` 为基准，进入对应子目录后再运行。

---

## 1. 后端（backend）

工作目录：`backend`

### 1.1 激活 Python 虚拟环境

```powershell
cd backend
.\venv\Scripts\Activate.ps1
```

> 首次使用需先创建虚拟环境并安装依赖，见 [backend/README.md](../../backend/README.md)。

### 1.2 启动 API（开发模式，热重载）

```powershell
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

| 说明 | |
|------|--|
| 用途 | 日常本地开发，代码改动后自动重启 |
| 访问 | Swagger：<http://localhost:8000/docs> · 健康检查：<http://localhost:8000/health> |
| 注意 | 单进程运行；**不能与 `--workers` 同时使用**（uvicorn 限制） |

### 1.3 启动 API（多 Worker，无热重载）

```powershell
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
```

| 说明 | |
|------|--|
| 用途 | 模拟生产多进程负载，或压测 HTTP 接口 |
| Worker 数 | 可按 CPU 核数调整，如 `--workers 2` |
| 注意 | 无 `--reload`；计费引擎 worker **不要**在此进程内开启（见 1.4） |

### 1.4 启动运费计算 Worker（独立进程）

运单/合同变更后的异步运费重算，由独立 worker 扫 `biz_freight_calc_task` 表执行。**本地开发建议单独开一个终端**（与 API 进程分离，行为与线上一致）。

```powershell
cd backend
.\venv\Scripts\Activate.ps1
python -m app.workers.freight_calc_main
```

| 说明 | |
|------|--|
| 用途 | 异步执行运费计算任务（创建运单、改合同等触发的 pending 任务） |
| 日志关键字 | 启动成功可见 `[freight-worker] 启动` |
| 可选环境变量 | `FREIGHT_CALC_WORKER_INTERVAL=5`（扫表间隔秒）· `FREIGHT_CALC_WORKER_BATCH=20`（每轮处理上限） |

**简化方案（仅单进程 API 时）：** 在 `backend/.env` 中设置 `FREIGHT_CALC_WORKER_ENABLED=1`，则 API 进程内嵌启动 scheduler，无需另开终端。  
⚠️ 不要与「多 Worker API」（1.3）同时启用，否则多个进程会重复扫表。

### 1.5 行政区域高德同步（平台库）

`.env` 中配置 `AMAP_WEB_SERVICE_KEY`（高德 Web 服务 Key，勿提交 git）。

```powershell
cd backend
make migrate-apply-local          # 应用平台库迁移（含 sys_regions 坐标列）
```

运营后台 → **数据同步 → 行政区域同步** → 发起同步（约 15~20 分钟）。

**存量租户坐标回填**（平台同步完成后执行）：

```powershell
python -m scripts.fix.backfill_tenant_region_coords --dry-run
python -m scripts.fix.backfill_tenant_region_coords
python -m scripts.fix.backfill_tenant_region_coords --tenant-code 1001
```

| 说明 | |
|------|--|
| 用途 | 将平台 `sys_regions` 的经纬度写入各租户 `biz_region`（仅 `source=0` 且 `level≤3`） |
| 线上部署 | 先备份 `sys_regions` → 部署代码 → `alembic upgrade head` → 手动触发同步 → 执行回填脚本 |

## 2. Mock 测试数据（backend/scripts/mockdata）

工作目录：`backend`（需已激活虚拟环境，且 `.env` 能连上目标租户库）

通用格式：

```powershell
python scripts/mockdata/<脚本名>.py --tenant-code <租户编码> [选项]
```

| 选项 | 说明 |
|------|------|
| `--tenant-code` | **必填**，租户编码（本地开发环境：`1001`） |
| `--count` | 生成条数（各脚本默认值不同） |
| `--dry-run` | 只打印摘要，**不写库**（建议首次先跑） |
| `--seed` | 随机种子，便于复现同一批数据 |

查看某脚本全部参数：

```powershell
python scripts/mockdata/mock_tenant_customers.py --help
```

### 2.1 建议执行顺序

部分脚本依赖库内已有主数据，建议按以下顺序生成：

```
客户 → 承运商 → 挂车 → 车辆 → 驾驶员 → 运价合同 → 运单
```

### 2.2 各脚本命令

**客户**（`biz_customer`）

```powershell
python scripts/mockdata/mock_tenant_customers.py --tenant-code 1001 --count 30
```

**承运商**（`biz_carrier` + 结算账户）

```powershell
python scripts/mockdata/mock_tenant_carriers.py --tenant-code 1001 --count 15
```

**挂车**（`biz_trailer`，车辆脚本可能关联挂车，宜先生成）

```powershell
python scripts/mockdata/mock_tenant_trailers.py --tenant-code 1001 --count 20
```

**车辆**（`biz_vehicle`）

```powershell
python scripts/mockdata/mock_tenant_vehicles.py --tenant-code 1001 --count 20
```

**驾驶员**（`biz_driver` 及关联子表）

```powershell
python scripts/mockdata/mock_tenant_drivers.py --tenant-code 1001 --count 30
```

**运价合同**（`biz_freight_contract` + `biz_freight_rate`，需库内已有客户、地区）

```powershell
python scripts/mockdata/mock_tenant_freight_contracts.py --tenant-code 1001 --count 10
```

**运单**（`biz_waybill` + 货物明细，需客户、地区、经销商、品牌/车系等主数据）

```powershell
python scripts/mockdata/mock_tenant_waybills.py --tenant-code 1001 --count 15
```

### 2.3 常用变体

**先试跑、不写库：**

```powershell
python scripts/mockdata/mock_tenant_waybills.py --tenant-code 1001 --count 5 --dry-run
```

**固定随机结果（便于复现）：**

```powershell
python scripts/mockdata/mock_tenant_freight_contracts.py --tenant-code 1001 --count 5 --seed 42
```

> 更详细的表结构说明与依赖关系见 [backend/scripts/mockdata/README.md](../../backend/scripts/mockdata/README.md)。

## 3. 前端

各前端项目独立目录，首次需先执行 `npm install` 安装依赖。

### 3.1 管理后台（console）

工作目录：`frontend/console`

```powershell
cd frontend/console
npm run dev
```

| 说明 | |
|------|--|
| 用途 | 平台管理后台（租户、菜单、系统配置等） |
| 访问 | <http://localhost:5173> |
| 默认账号 | 用户名 `admin` · 密码 `admin123` |

### 3.2 企业端（client）

工作目录：`frontend/client`

```powershell
cd frontend/client
npm run dev
```

| 说明 | |
|------|--|
| 用途 | 物流企业业务端（运单、计费、运力等） |
| 访问 | <http://localhost:5174> |
| 注意 | 需先在管理后台创建企业及企业超管账号 |

### 3.3 产品官网（website）

工作目录：`frontend/website`

```powershell
cd frontend/website
npm run dev
```

| 说明 | |
|------|--|
| 用途 | 产品宣传官网 |
| 访问 | <http://localhost:5175> |
