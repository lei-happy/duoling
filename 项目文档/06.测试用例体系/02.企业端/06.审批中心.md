# 审批中心 测试用例

> **对应需求**：`项目文档/02.需求文档/02.企业端/08.审批中心/**`
> **对应后端**：`backend/app/modules/client/api/approval/**`、`services/**`
> **对应前端**：`frontend/client/src/views/approval`
> **测试脚本**：`backend/tests/client/test_approval_flow.py`（核心逻辑 49 用例，2026-07-09 补齐）；DB 强相关链路仍待补

## 接口清单（节选）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST/PUT | `/api/client/approval/flow` | 审批流定义 |
| GET | `/api/client/approval/center` | 审批中心（待我审批/我发起/抄送我） |
| POST | `/api/client/approval/center/{id}/approve` | 通过 |
| POST | `/api/client/approval/center/{id}/reject` | 驳回 |

## 说明

审批中心以「业务模块注册回调（biz_type → callback）」方式与各业务解耦
（见 `events._register_approval_callbacks`，当前已注册社会运力入池审批）。
审批链路强依赖：审批流定义 + 业务单据 + 审批人角色 + 回调副作用，需较多种子数据与
跨模块状态驱动，本轮以文档用例登记，脚本待补。
